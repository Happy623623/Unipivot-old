## 정한 것

1. **푸시는 알림함 행을 닫은 뒤에 보낸다.** DB 작업(보낼 것 고르기·닫기)을 먼저 끝내고, 그 번호를 받아
   바깥(푸시 서비스)을 부른다 — 트랜잭션을 쥔 채로 바깥을 부르지 않는다(api/CLAUDE.md).
2. **푸시가 실패해도 알림은 보낸 것으로 남긴다.** 다시 보내려면 알림을 `pending`으로 되돌려야 하는데,
   그러면 같은 알림이 두 번 갈 수 있다. 명세 10장이 "같은 알림은 한 번만"이라 **한 번 빠뜨리는 쪽**을
   택했다. 알림함에는 그대로 남아서 학생이 볼 수 있다(F-35가 그 대비다).
3. **사라진 구독(404·410)은 지운다.** 브라우저를 지웠거나 알림을 끈 구독이다. 그냥 두면 발송마다
   실패가 쌓인다. 응답의 `push_dropped`로 몇 개를 지웠는지 센다.
4. **암호화는 `http-ece`에 맡겼다.** RFC 8291을 직접 구현하면 우리 시험은 통과하면서 실제 브라우저에서는
   풀리지 않는 일이 생긴다. 대신 **구독 비밀 키로 풀어 보는 시험**을 뒀다 — 우리가 만든 본문이 정말
   브라우저가 풀 수 있는 모양인지 보는 유일한 방법이다.
5. **메시지마다 임시 키를 새로 만든다**(RFC 8291 3.1). 같은 키를 다시 쓰면 두 메시지가 같은 비밀에서
   나와 안전하지 않다. 되돌림 시험으로 이 자리를 지켰다(고정 키로 바꾸면 시험이 깨진다).
6. **VAPID 공개 키는 저장하지 않고 비밀 키에서 다시 만든다.** 설정에 둘을 따로 두면 서로 안 맞는 짝이
   들어갈 수 있고, 그러면 푸시 서비스가 조용히 거절한다.
7. **구독 주소가 유일 키다.** 같은 주소가 다시 오면 키만 갱신하고, **다른 사용자가 같은 주소로 구독하면
   주인이 바뀐다** — 한 브라우저를 번갈아 쓰는 경우다. 그 주소로 가는 푸시는 지금 로그인한 사람의
   알림이어야 한다.
8. **`httpx`를 명시 의존으로 올렸다.** 앱 코드 일곱 곳이 `import httpx`를 하는데 `pyproject.toml`에는
   개발 의존으로만 있었다(실제로는 `google-genai`가 끌어오는 것에 얹혀 있었다). google-genai가 어느
   날 그것을 빼면 운영에서 import가 터진다. 푸시도 httpx로 보내니 이 PR에서 함께 바로잡았다.
9. **누르면 갈 주소는 web과 같은 규칙으로 만든다.** 알림함에서 누르는 곳과 푸시에서 누르는 곳이 다르면
   학생이 다른 화면으로 간다. 규칙을 명세 10장에 적고 서버·web이 그것을 본다(시험이 규칙을 못 박는다).
10. **시나리오에도 넣었다.** S14(마감 D-3·D-1)가 구독을 등록하고 → 발송 → **녹화한 푸시 서비스가
    받은 본문을 구독 비밀 키로 풀어** 제목·본문·주소를 확인하고 → 구독을 해제하면 푸시가 더 가지
    않는 것까지 본다. 푸시 서비스는 녹화한 것이라 **네트워크를 쓰지 않는다**(PRD 8장).
11. **서비스 워커와 "알림 켜기" 화면은 다음 PR이다.** 이 PR은 서버까지다 — 브라우저가 구독을 만들어
    올리는 쪽(web)은 키를 넣은 뒤에 붙이는 게 순서다.

## 확인한 것

| 확인 | 결과 |
| --- | --- |
| 암호화 왕복 | 우리가 만든 본문을 구독 비밀 키로 풀어 **페이로드 JSON이 그대로** 나오는지 봤다. 다른 키로는 풀리지 않는다 |
| 임시 키 | 같은 내용을 두 번 암호화하면 salt와 임시 공개 키가 **매번 다르다**(RFC 8291 3.1) |
| VAPID 토큰 | 머리값의 공개 키로 토큰을 검사해 `aud`(푸시 서비스 출처)·`sub`·`exp`(12시간)를 확인했다 |
| 머리값 | `Content-Encoding: aes128gcm` · `TTL: 86400` · `Content-Type: application/octet-stream` |
| 발송 결과 갈래 | 201 → 보냄 · 404·410 → 구독 삭제 · 500 → 실패만 세기 · 키 없음 → 푸시 서비스를 아예 부르지 않음 |
| 발송 작업 전체 | 실제 DB로 "예약 → 발송 → 푸시 → 사라진 구독 삭제"를 돌려 `{sent, pushable, pushed, push_dropped}`를 못 박았다. 410이 와도 알림함 행은 `succeeded`로 남는다 |
| S14(시나리오) | 구독 등록(201) → D-3 발송에서 `pushed` 1 → 받은 머리값(VAPID·aes128gcm)과 **복호화한 페이로드**(종류·제목·본문·주소) → 구독 해제(204) → D-1 발송에서 `pushed` 0 |
| 구독 API | 201·204, https 아닌 주소 422, 키 없는 요청 422, 로그인 없으면 401, 내 구독만 삭제 |
| 구독 SQL | 같은 주소 두 번 → 한 행 · 다른 사용자가 같은 주소 → 주인 바뀜 · 푸시를 끈 사람·구독 없는 사람은 발송 대상에서 빠짐 |
| 보내는 본문 | 평문 제목("발송 장학")도 `notification_id` 글자도 **본문에 보이지 않는다**(암호화됐다) |
| 테스트 | 1358 passed(DB 포함) · DB 없이 1024 passed, 334 skipped |
| 시나리오 | **18/18 통과**(확인 260개). S14가 구독 등록 → 발송 → **본문 복호화** → 구독 해제 → 푸시 안 감까지 본다 |
| S14 시계 | 세 개 시각에서 모두 통과(10/12, 12/28, 2027-01-05) |

## 검토에서 고친 것

| 처음 만든 것 | 무엇이 틀렸나 | 고친 것 |
| --- | --- | --- |
| `http_ece.encrypt`에 임시 키를 주지 않았다 | "DH requires a private_key"로 바로 터졌다. aes128gcm은 **보내는 쪽 임시 키**가 있어야 한다 | 메시지마다 새 임시 키를 만들어 넘긴다 |
| 임시 키 시험이 없었다 | 되돌림 시험에서 "고정 키로 바꾸기"가 **살아남았다** — 한 번 만든 키를 계속 쓰는 버그를 아무도 못 잡는다 | 본문 머리(salt·임시 공개 키)가 매번 다른지 보는 시험을 더했다 |
| `repo.send()`가 수만 돌려줬다 | 푸시를 보낼 알림 **번호**를 알 수 없어 발송기에 넘길 것이 없었다 | `Sent(result, ids)`로 번호를 함께 돌려준다(응답에는 번호가 없다) |
| 시험이 공지 표에 남긴 행을 치우지 않았다 | 공지는 과목 공통 표라 사용자를 지워도 남는다. 다른 시험이 그 행을 보고 깨졌다(전체로 돌릴 때만) | 시험이 자기 행을 치우고, 공지 시험들의 조회를 **그 과목으로 좁혔다** |
| `httpx`를 개발 의존에 둔 채였다 | 앱이 직접 import하는데 `google-genai`가 끌어오는 것에 얹혀 있었다 | 명시 의존으로 올렸다(개발 의존에서는 뺐다) |

## 남은 것

- **web(다음 PR)**: 서비스 워커(`/sw.js`)와 "알림 켜기" 버튼, 권한 거절·미지원 브라우저 안내,
  구독을 서버에 올리기·해제. 키를 `.env`에 넣은 뒤에 붙이는 게 순서다.
- **실제 브라우저로 끝까지**: 샌드박스에서는 FCM에 보낼 수 없어 **녹화한 푸시 서비스**로만 확인했다
  (본문은 구독 키로 풀어 봤다). 키를 넣고 Chrome에서 한 번 받아 보는 것이 마지막 확인이다 — 그때
  발송 응답의 `pushed`가 1이면 끝이다.
- **아이폰**: iOS는 홈 화면에 추가한 PWA만 웹 푸시를 받는다(PRD의 "데스크톱·안드로이드 브라우저"도
  그래서다). 안내 문구를 web에서 어떻게 보여 줄지는 다음 PR에서 정한다.
- **발송 상한**: 한 번에 500건을 보내고(`SEND_LIMIT`) 구독마다 순서대로 부른다. 사용자가 늘면
  동시에 보내는 쪽(`asyncio.gather`)으로 바꿀 자리다 — 지금은 몇 건이라 그대로 둔다.

`type`: ERD `notification_type`(`new_eligible`, `new_assignment`, `new_material`, `schedule_change`, `task_due`, `deadline_soon`, `profile_needed`)

그 줄 **뒤에** 이 여덟 줄을 붙여 줘.

- `url`은 **알림함에서 누르는 곳과 같은 화면**이다(같은 규칙을 서버와 web이 함께 쓴다).
  공고 → `/opportunities/{id}`(정보 필요 알림은 `?focus=profile_input`), 플래너 할 일 → `/planner`,
  LMS 과제·자료·공지 → `/academics/{course_id}?tab=assignments|materials|announcements`.
  과목을 찾을 수 없으면(수강을 뺐다) `/academics`, 가리킬 대상이 없으면 `/`다
- `body`는 없을 수 있다(null). `title`은 늘 있다
- 본문은 **구독 키로 암호화해서** 보낸다(RFC 8291 aes128gcm). 머리값은 `Authorization: vapid t=<JWT>, k=<공개 키>`,
  `Content-Encoding: aes128gcm`, `TTL: 86400`이다. 서버에 VAPID 키가 없으면 푸시를 보내지 않고 알림함에만 쌓는다
- 푸시가 실패해도 알림은 보낸 것으로 남는다. **같은 알림을 두 번 보내지 않는다**(한 번 빠뜨리는 쪽을 택했다)

[5] 12장 내부 작업 표의 send-notifications 행. 이 줄을 찾아서

| `POST /internal/jobs/send-notifications` | 스케줄러(5분) | 예약된 알림 발송. 보내기 전에 숨김을 다시 보고, `profile_needed`는 사용자당 KST 하루 1건까지만 보낸다. 푸시 구독이 없거나 푸시를 끈 사용자는 푸시만 건너뛰고 행은 알림함에 남는다. 응답은 `{due, sent, pushable, skipped}`이고 `pushable`은 푸시를 보낼 수 있었던 알림 수다 |

이것으로 바꿔 줘(한 줄이다).

| `POST /internal/jobs/send-notifications` | 스케줄러(5분) | 예약된 알림 발송. 보내기 전에 숨김을 다시 보고, `profile_needed`는 사용자당 KST 하루 1건까지만 보낸다. 푸시 구독이 없거나 푸시를 끈 사용자는 푸시만 건너뛰고 행은 알림함에 남는다. 응답은 `{due, sent, pushable, skipped, pushed, push_failed, push_dropped}`다 — `pushable`은 푸시를 보낼 수 있었던 알림 수, `pushed`는 푸시 서비스가 받아 준 구독 수(한 알림에 구독이 여러 개면 여러 번 센다), `push_failed`는 실패한 구독 수, `push_dropped`는 사라져서(404·410) 지운 구독 수다. 알림함 행을 닫은 뒤에 푸시를 보낸다 |
````

#### `api/app/push/keys.py`

```python
"""VAPID 키 (F-33). 푸시 서비스에 "이 서버가 보냈다"고 밝히는 P-256 키 한 쌍이다.

키는 **설정에서만** 읽는다(`api/.env`). 레포에는 넣지 않는다 — `.env.example`에는 빈 칸만 있다.
키가 없으면 푸시를 보내지 않고 알림함에만 쌓는다(명세 12장). 서버는 그래도 뜬다.

키를 만들려면 api 폴더에서:

    uv run python -m app.push.keys

찍힌 두 줄을 `api/.env`에 붙이고, 공개 키는 web의 `NEXT_PUBLIC_VAPID_PUBLIC_KEY`에도 넣는다
(브라우저가 `PushManager.subscribe()`에 쓴다). **비밀 키는 서버에만 둔다.**
"""

import base64
from dataclasses import dataclass

from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.hazmat.primitives.serialization import Encoding, PublicFormat

CURVE = ec.SECP256R1()
_PRIVATE_BYTES = 32


def b64u(raw: bytes) -> str:
    """패딩 없는 base64url. 웹 푸시의 모든 키·값이 이 꼴이다."""
    return base64.urlsafe_b64encode(raw).rstrip(b"=").decode()


def unb64u(value: str) -> bytes:
    """패딩이 빠진 base64url도 읽는다(브라우저가 패딩 없이 준다)."""
    padded = value + "=" * (-len(value) % 4)
    return base64.urlsafe_b64decode(padded.encode())


@dataclass(frozen=True)
class VapidKeys:
    """서버의 VAPID 키 한 쌍과 연락처(`mailto:` 또는 주소)."""

    private_key: ec.EllipticCurvePrivateKey
    public_bytes: bytes  # 65바이트 비압축 공개 키(푸시 서비스에 그대로 보낸다)
    subject: str

    @property
    def public_b64(self) -> str:
        return b64u(self.public_bytes)


def load_keys(*, private_key: str, subject: str) -> VapidKeys | None:
    """설정 값에서 키를 읽는다. 비었거나 읽을 수 없으면 None이다(푸시를 건너뛴다).

    공개 키는 비밀 키에서 다시 만든다 — 설정에 둘을 따로 두면 서로 안 맞는 짝이 들어갈 수 있다.
    """
    if not private_key or not subject:
        return None
    try:
        raw = unb64u(private_key)
        if len(raw) != _PRIVATE_BYTES:
            raise ValueError(f"비밀 키가 {_PRIVATE_BYTES}바이트가 아니에요: {len(raw)}")
        key = ec.derive_private_key(int.from_bytes(raw, "big"), CURVE)
    except Exception:
        return None
    return VapidKeys(
        private_key=key,
        public_bytes=key.public_key().public_bytes(Encoding.X962, PublicFormat.UncompressedPoint),
        subject=subject,
    )


def generate_keys() -> tuple[str, str]:
    """새 키 한 쌍(비밀, 공개)을 base64url로. 시험과 아래 CLI가 쓴다."""
    key = ec.generate_private_key(CURVE)
    private = key.private_numbers().private_value.to_bytes(_PRIVATE_BYTES, "big")
    public = key.public_key().public_bytes(Encoding.X962, PublicFormat.UncompressedPoint)
    return b64u(private), b64u(public)


def main() -> None:
    private, public = generate_keys()
    print("# api/.env 에 붙여 주세요 (비밀 키는 서버에만 둡니다)")
    print(f"VAPID_PRIVATE_KEY={private}")
    print("VAPID_SUBJECT=mailto:본인메일@hanyang.ac.kr")
    print()
    print("# web/.env.local 에 붙여 주세요 (브라우저가 구독할 때 씁니다)")
    print(f"NEXT_PUBLIC_VAPID_PUBLIC_KEY={public}")


if __name__ == "__main__":
    main()
```

#### `api/app/push/vapid.py`

```python
"""VAPID 머리값 (F-33, RFC 8292). 푸시 서비스에 "이 서버가 보냈다"고 밝힌다.

푸시 주소의 **출처(origin)마다** 토큰을 하나 만들어 쓴다(`aud`). 토큰은 ES256으로 서명하고
만료는 12시간 뒤다(RFC 권고 상한 24시간). 같은 발송에서 같은 출처면 토큰을 다시 쓴다.

aes128gcm 인코딩에서는 머리값 하나에 토큰과 공개 키를 함께 담는다:

    Authorization: vapid t=<JWT>, k=<base64url 공개 키>
"""

import time
from urllib.parse import urlsplit

import jwt

from app.push.keys import VapidKeys

EXPIRY_SECONDS = 12 * 60 * 60  # 토큰 수명. 푸시 서비스는 24시간을 넘기면 거절한다


def origin_of(endpoint: str) -> str:
    """구독 주소의 출처(스킴 + 호스트). VAPID 토큰의 `aud`다."""
    parts = urlsplit(endpoint)
    if not parts.scheme or not parts.netloc:
        raise ValueError(f"푸시 주소가 아니에요: {endpoint[:40]}")
    return f"{parts.scheme}://{parts.netloc}"


def authorization(keys: VapidKeys, endpoint: str, *, now: float | None = None) -> str:
    """그 주소에 보낼 `Authorization` 머리값."""
    issued = int(now if now is not None else time.time())
    token = jwt.encode(
        {"aud": origin_of(endpoint), "exp": issued + EXPIRY_SECONDS, "sub": keys.subject},
        keys.private_key,
        algorithm="ES256",
    )
    return f"vapid t={token}, k={keys.public_b64}"
```

#### `api/app/push/payload.py`

```python
"""서비스 워커에 보낼 푸시 페이로드와 누르면 갈 주소 (F-33, API 명세 10장).

주소 규칙은 **web과 같아야 한다**(`web/src/lib/notificationRoute.ts` + `routes.ts`). 알림함에서
누르는 곳과 푸시에서 누르는 곳이 다르면 학생이 다른 화면으로 간다. 규칙을 명세 10장에 적어 두고
두 쪽이 그것을 본다.

링크가 없는 알림(대상 id가 하나도 없는 알림)은 홈으로 보낸다 — 푸시는 눌러야 쓸모가 있다.
"""

import json
from dataclasses import dataclass
from urllib.parse import quote

HOME = "/"
ACADEMICS = "/academics"
TABS: dict[str, str] = {
    "lms_assignment": "assignments",
    "lms_module_item": "materials",
    "lms_announcement": "announcements",
}


@dataclass(frozen=True)
class PushPayload:
    """서비스 워커가 그대로 읽는 JSON(명세 10장의 "푸시 페이로드")."""

    type: str
    title: str
    body: str | None
    url: str
    notification_id: str

    def to_json(self) -> bytes:
        return json.dumps(
            {
                "type": self.type,
                "title": self.title,
                "body": self.body,
                "url": self.url,
                "notification_id": self.notification_id,
            },
            ensure_ascii=False,
        ).encode()


def url_for(
    *,
    kind: str,
    link_type: str | None,
    link_id: str | None,
    course_id: str | None,
) -> str:
    """알림 하나가 가리키는 web 주소. `routeToHref`와 같은 꼴을 만든다."""
    if link_type is None or link_id is None:
        return HOME
    if link_type == "opportunity":
        focus = "?focus=profile_input" if kind == "profile_needed" else ""
        return f"/opportunities/{quote(link_id, safe='')}{focus}"
    if link_type == "planner_task":
        return "/planner"
    # lms_* 알림은 과목 탭으로 간다. 과목을 못 찾으면(수강을 뺐다) 학업 화면까지만
    if course_id is None:
        return ACADEMICS
    tab = TABS.get(link_type)
    suffix = f"?tab={tab}" if tab else ""
    return f"{ACADEMICS}/{quote(course_id, safe='')}{suffix}"


def payload_for(
    *,
    notification_id: str,
    kind: str,
    title: str,
    body: str | None,
    link_type: str | None,
    link_id: str | None,
    course_id: str | None,
) -> PushPayload:
    return PushPayload(
        type=kind,
        title=title,
        body=body,
        url=url_for(kind=kind, link_type=link_type, link_id=link_id, course_id=course_id),
        notification_id=notification_id,
    )
```

#### `api/app/push/send.py`

```python
"""푸시 발송 (F-33, RFC 8291). 페이로드를 구독 키로 암호화해 푸시 서비스에 보낸다.

한 알림을 그 사용자의 **구독마다** 한 번씩 보낸다(브라우저·기기별로 구독이 따로다). 발송 결과는
세 갈래다.

- 보냈다(201·200·202): 셀 뿐이다. 알림함 행은 이미 `succeeded`다
- 구독이 사라졌다(404·410): 그 구독을 지운다. 브라우저를 지웠거나 알림을 껐다
- 그 밖(5xx·시간 초과): 로그만 남기고 둔다. 알림은 이미 보낸 것으로 닫혀 **다시 보내지 않는다**
  — 같은 알림을 두 번 보내는 쪽이 한 번 빠뜨리는 쪽보다 나쁘다(명세 10장: 같은 알림은 한 번만)

암호화는 `http_ece`(aes128gcm)에 맡긴다. 직접 구현하면 우리 시험은 통과하면서 실제 브라우저에서는
풀리지 않는 일이 생긴다 — 이 부분은 검증된 구현을 쓴다.
"""

import logging
from collections.abc import Sequence
from dataclasses import dataclass, field

import http_ece
import httpx
from cryptography.hazmat.primitives.asymmetric import ec

from app.push.keys import VapidKeys, unb64u
from app.push.payload import PushPayload
from app.push.vapid import authorization, origin_of

logger = logging.getLogger(__name__)

TTL_SECONDS = 24 * 60 * 60  # 푸시 서비스가 기기를 못 깨우면 이만큼 들고 있는다
TIMEOUT_SECONDS = 10.0
GONE = (404, 410)  # 구독이 사라졌다는 뜻(RFC 8030)
_OK = (200, 201, 202)
_RECORD_SIZE = 4096


@dataclass(frozen=True)
class Subscription:
    """브라우저 구독 하나. 키는 base64url 그대로 담는다."""

    id: str
    endpoint: str
    p256dh: str
    auth: str


@dataclass(frozen=True)
class PushTarget:
    """알림 하나와 그 사용자의 구독들."""

    payload: PushPayload
    subscriptions: tuple[Subscription, ...]


@dataclass
class PushResult:
    """발송 한 묶음의 결과."""

    notifications: int = 0  # 푸시를 보낸 알림 수(구독이 여러 개면 한 알림에 여러 번 보낸다)
    sent: int = 0  # 보낸 구독 수
    gone: list[str] = field(default_factory=list)  # 지워야 하는 구독 주소
    failed: int = 0


def encrypt(payload: PushPayload, subscription: Subscription) -> bytes:
    """RFC 8291 aes128gcm 본문. 구독의 공개 키·비밀 값으로만 풀 수 있다.

    **메시지마다 새 임시 키**를 만든다(RFC 8291 3.1). 같은 키를 다시 쓰면 두 메시지의 암호가
    같은 비밀에서 나와 안전하지 않다. 임시 공개 키는 본문 머리에 함께 들어가므로 따로 보내지 않는다.
    """
    ephemeral = ec.generate_private_key(ec.SECP256R1())
    return http_ece.encrypt(
        payload.to_json(),
        private_key=ephemeral,
        dh=unb64u(subscription.p256dh),
        auth_secret=unb64u(subscription.auth),
        version="aes128gcm",
        rs=_RECORD_SIZE,
    )


class PushSender:
    """푸시 서비스에 보내는 쪽. 키가 없으면 아무것도 보내지 않는다(설정이 비었다)."""

    def __init__(self, keys: VapidKeys | None, *, client: httpx.AsyncClient | None = None) -> None:
        self.keys = keys
        self.client = client

    async def send(self, targets: Sequence[PushTarget]) -> PushResult:
        """알림마다 그 사용자의 구독 전체에 보낸다. 사라진 구독 주소를 함께 돌려준다."""
        result = PushResult()
        if self.keys is None or not targets:
            return result
        client = self.client or httpx.AsyncClient(timeout=TIMEOUT_SECONDS)
        own = self.client is None
        try:
            for target in targets:
                result.notifications += 1
                for subscription in target.subscriptions:
                    await self._one(client, target.payload, subscription, result)
        finally:
            if own:
                await client.aclose()
        return result

    async def _one(
        self,
        client: httpx.AsyncClient,
        payload: PushPayload,
        subscription: Subscription,
        result: PushResult,
    ) -> None:
        assert self.keys is not None
        try:
            body = encrypt(payload, subscription)
            headers = {
                "Authorization": authorization(self.keys, subscription.endpoint),
                "Content-Encoding": "aes128gcm",
                "Content-Type": "application/octet-stream",
                "TTL": str(TTL_SECONDS),
                "Urgency": "normal",
            }
            response = await client.post(subscription.endpoint, content=body, headers=headers)
        except Exception as exc:  # 주소가 이상하거나 네트워크가 막혔다
            logger.warning("푸시를 보내지 못했어요: %r", exc)
            result.failed += 1
            return
        if response.status_code in _OK:
            result.sent += 1
            return
        if response.status_code in GONE:
            # 브라우저를 지웠거나 알림을 껐다. 다음 발송에서 또 시도하지 않게 구독을 지운다
            logger.info("사라진 푸시 구독을 지워요: %s", origin_of(subscription.endpoint))
            result.gone.append(subscription.endpoint)
            return
        logger.warning("푸시 서비스가 거절했어요: %s %s", response.status_code, response.text[:120])
        result.failed += 1
```

#### `api/app/repositories/push.py`

```python
"""웹 푸시 구독 SQL (F-33, ERD 3-1). 구독 저장·해제와 발송 대상 찾기.

`endpoint`가 유일 키다(브라우저·기기마다 다른 주소를 준다). 같은 주소가 다시 오면 키만 갱신하고,
**다른 사용자가 같은 주소로 구독하면 주인이 바뀐다** — 한 브라우저를 두 사람이 번갈아 쓰는 경우다.
그 주소로 가는 푸시는 지금 로그인한 사람의 알림이어야 한다.

발송 대상(`targets`)은 **푸시를 끄지 않은 사용자**의 구독만 모은다(`user_settings.push_enabled`).
알림함 행은 푸시와 상관없이 쌓이므로(F-35) 여기서 빠져도 알림은 남는다.
"""

from collections.abc import Sequence
from dataclasses import dataclass
from typing import Annotated, Any

from fastapi import Depends
from psycopg import AsyncConnection

from app.db import get_conn
from app.push.payload import payload_for
from app.push.send import PushTarget, Subscription

_UPSERT = (
    "insert into push_subscriptions (user_id, endpoint, p256dh, auth, user_agent)"
    " values (%(uid)s, %(endpoint)s, %(p256dh)s, %(auth)s, %(agent)s)"
    " on conflict (endpoint) do update set user_id = excluded.user_id,"
    " p256dh = excluded.p256dh, auth = excluded.auth, user_agent = excluded.user_agent"
    " returning (xmax = 0) as inserted"
)
# 보낸 알림 + 그 사용자의 구독. 링크 칸은 알림함(_LIST)과 같은 규칙으로 풀어 준다
_TARGETS = (
    "select n.id, n.type, n.title, n.body, n.opportunity_id, n.planner_task_id,"
    " n.lms_assignment_id, n.lms_module_item_id, n.lms_announcement_id,"
    " coalesce("
    "   (select a.lms_course_id from lms_assignments a where a.id = n.lms_assignment_id"
    "    and a.user_id = n.user_id),"
    "   (select lc.id from lms_module_items mi join lms_courses lc on lc.user_id = n.user_id"
    "    and lc.canvas_course_id = mi.canvas_course_id where mi.id = n.lms_module_item_id),"
    "   (select lc.id from lms_announcements an join lms_courses lc on lc.user_id = n.user_id"
    "    and lc.canvas_course_id = an.canvas_course_id where an.id = n.lms_announcement_id)"
    " ) as course_id,"
    " q.id as subscription_id, q.endpoint, q.p256dh, q.auth"
    " from notifications n"
    " join push_subscriptions q on q.user_id = n.user_id"
    " left join user_settings s on s.user_id = n.user_id"
    " where n.id = any(%(ids)s::uuid[]) and coalesce(s.push_enabled, true)"
    " order by n.id, q.created_at, q.id"
)
_LINKS: tuple[tuple[str, str], ...] = (
    ("opportunity", "opportunity_id"),
    ("planner_task", "planner_task_id"),
    ("lms_assignment", "lms_assignment_id"),
    ("lms_module_item", "lms_module_item_id"),
    ("lms_announcement", "lms_announcement_id"),
)


@dataclass(frozen=True)
class SavedSubscription:
    id: str
    created: bool  # 처음 등록이면 True, 같은 주소를 갱신했으면 False


class PushRepository:
    def __init__(self, conn: AsyncConnection) -> None:
        self.conn = conn

    async def save(
        self, user_id: str, *, endpoint: str, p256dh: str, auth: str, user_agent: str | None
    ) -> bool:
        """구독을 저장한다. 처음 등록이면 True(같은 주소를 갱신했으면 False)."""
        row = await self._row(
            _UPSERT,
            {
                "uid": user_id,
                "endpoint": endpoint,
                "p256dh": p256dh,
                "auth": auth,
                "agent": user_agent,
            },
        )
        assert row is not None
        return bool(row["inserted"])

    async def remove(self, user_id: str, endpoint: str) -> int:
        """내 구독만 지운다. 남의 주소를 보내도 아무것도 지워지지 않는다(204는 그대로 준다)."""
        cursor = await self.conn.execute(
            "delete from push_subscriptions where user_id = %s and endpoint = %s",
            (user_id, endpoint),
        )
        return max(cursor.rowcount, 0)

    async def drop_endpoints(self, endpoints: Sequence[str]) -> int:
        """푸시 서비스가 "사라졌다"(404·410)고 한 구독을 지운다. 사용자를 가리지 않는다."""
        if not endpoints:
            return 0
        cursor = await self.conn.execute(
            "delete from push_subscriptions where endpoint = any(%s::text[])", (list(endpoints),)
        )
        return max(cursor.rowcount, 0)

    async def count(self, user_id: str) -> int:
        row = await self._row(
            "select count(*) as count from push_subscriptions where user_id = %s", (user_id,)
        )
        return int(row["count"]) if row else 0

    async def targets(self, notification_ids: Sequence[str]) -> list[PushTarget]:
        """그 알림들의 푸시 대상. 알림 하나에 구독이 여러 개면 한 묶음으로 모은다."""
        if not notification_ids:
            return []
        rows = await self._rows(_TARGETS, {"ids": list(notification_ids)})
        grouped: dict[str, tuple[dict[str, Any], list[Subscription]]] = {}
        for row in rows:
            key = str(row["id"])
            if key not in grouped:
                grouped[key] = (row, [])
            grouped[key][1].append(
                Subscription(
                    id=str(row["subscription_id"]),
                    endpoint=row["endpoint"],
                    p256dh=row["p256dh"],
                    auth=row["auth"],
                )
            )
        targets: list[PushTarget] = []
        for row, subscriptions in grouped.values():
            link_type, link_id = _link_of(row)
            targets.append(
                PushTarget(
                    payload=payload_for(
                        notification_id=str(row["id"]),
                        kind=row["type"],
                        title=row["title"],
                        body=row["body"],
                        link_type=link_type,
                        link_id=link_id,
                        course_id=str(row["course_id"]) if row["course_id"] else None,
                    ),
                    subscriptions=tuple(subscriptions),
                )
            )
        return targets

    async def _row(self, sql: str, params: Any) -> dict[str, Any] | None:
        return await (await self.conn.execute(sql, params)).fetchone()

    async def _rows(self, sql: str, params: Any) -> list[dict[str, Any]]:
        return await (await self.conn.execute(sql, params)).fetchall()


def _link_of(row: dict[str, Any]) -> tuple[str | None, str | None]:
    """알림함(`notifications._link`)과 같은 순서로 대상을 고른다."""
    for kind, column in _LINKS:
        if row[column] is not None:
            return kind, str(row[column])
    return None, None


def get_push_repo(conn: Annotated[AsyncConnection, Depends(get_conn)]) -> PushRepository:
    return PushRepository(conn)


PushRepoDep = Annotated[PushRepository, Depends(get_push_repo)]
```

"""웹 푸시 구독 (F-33, API 명세 10장). 브라우저 `PushManager.subscribe()` 결과를 그대로 받는다."""

from pydantic import BaseModel, Field, field_validator

ENDPOINT_MAX = 1000  # 푸시 주소(FCM은 200자 안쪽이지만 넉넉히 둔다)
KEY_MAX = 200
AGENT_MAX = 200


class SubscriptionKeys(BaseModel):
    """브라우저가 주는 두 값. base64url(패딩 없음)이다."""

    p256dh: str = Field(min_length=1, max_length=KEY_MAX)
    auth: str = Field(min_length=1, max_length=KEY_MAX)


class PushSubscriptionRequest(BaseModel):
    endpoint: str = Field(min_length=1, max_length=ENDPOINT_MAX)
    keys: SubscriptionKeys
    user_agent: str | None = Field(default=None, max_length=AGENT_MAX)

    @field_validator("endpoint")
    @classmethod
    def _https(cls, value: str) -> str:
        """https 주소만 받는다. http면 암호화한 본문이 평문 길로 나간다."""
        if not value.startswith("https://"):
            raise ValueError("https 주소만 받아요.")
        return value


class PushSubscribed(BaseModel):
    subscribed: bool = True


class PushUnsubscribeRequest(BaseModel):
    endpoint: str = Field(min_length=1, max_length=ENDPOINT_MAX)

"""웹 푸시 구독 (F-33, API 명세 10장). 브라우저가 구독을 만들면 여기에 올린다.

구독을 저장만 하고 어떤 값도 돌려주지 않는다 — 키는 브라우저가 이미 갖고 있고, 서버가 되돌려 줄
이유가 없다. 해제는 주소로 한다(`DELETE`). **내 구독만** 지울 수 있다.
"""

from fastapi import APIRouter, Response

from app.auth import CurrentUserDep
from app.repositories.push import PushRepoDep
from app.schemas.push import PushSubscribed, PushSubscriptionRequest, PushUnsubscribeRequest

router = APIRouter(prefix="/push", tags=["알림"])


@router.post("/subscriptions", status_code=201, response_model=PushSubscribed)
async def subscribe(
    body: PushSubscriptionRequest, user: CurrentUserDep, repo: PushRepoDep
) -> PushSubscribed:
    """구독을 저장한다. 같은 주소를 다시 보내면 키만 갱신한다(201은 그대로다)."""
    await repo.save(
        user.id,
        endpoint=body.endpoint,
        p256dh=body.keys.p256dh,
        auth=body.keys.auth,
        user_agent=body.user_agent,
    )
    return PushSubscribed()


@router.delete("/subscriptions", status_code=204, response_class=Response)
async def unsubscribe(
    body: PushUnsubscribeRequest, user: CurrentUserDep, repo: PushRepoDep
) -> Response:
    """구독을 지운다. 없는 주소여도 204다(브라우저가 이미 지웠을 수 있다)."""
    await repo.remove(user.id, body.endpoint)
    return Response(status_code=204)

def test_every_message_gets_a_new_ephemeral_key() -> None:

    aes128gcm 본문 머리는 `salt(16) | rs(4) | 키 길이(1) | 임시 공개 키(65)`다(RFC 8188).
