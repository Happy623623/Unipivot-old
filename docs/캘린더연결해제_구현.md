>
> 적용할 곳: **청년정책 정기 수집(앞 PR)까지 합친 main** 위 새 브랜치. **마이그레이션 없음**

## 정한 것

1. **Google 쪽 권한도 거둔다**(`https://oauth2.googleapis.com/revoke`). 학생이 "연결 해제"를 누르는
   뜻은 "이 앱이 내 캘린더를 못 보게 해 달라"다. 우리 토큰만 지우면 Google 계정 설정에는 이 앱이
   여전히 허용된 앱으로 남는다. PRD 169줄이 F-06을 P0로 둔 이유가 "개인정보 처리상 빠질 수 없다"라
   거두는 쪽이 그 뜻에 맞다. refresh token을 보내면 그 승인 전체가 풀린다.
2. **거두지 못해도 토큰은 지운다.** Google이 막힌 날 해제가 실패하면 학생은 끊을 길이 없다. 우리
   쪽은 그 순간부터 캘린더를 쓰지 않고, 못 거둔 권한은 학생이 Google 계정 설정에서 직접 거둘 수
   있다. 로그에 경고를 남긴다.
3. **이미 풀린 토큰(Google이 400)은 성공으로 본다.** 거두려던 것이 거둬진 상태다. 경고도 남기지
   않는다 — 흔한 경우(학생이 Google 쪽에서 먼저 끊음)라 로그가 지저분해진다.
4. **이미 넣은 일정은 캘린더에 그대로 둔다.** 설정의 LMS 자동 등록을 끌 때와 같은 규칙이다(명세 7장
   "이미 등록한 일정은 지우지 않는다"). `calendar_events` 기록도 남겨 다시 연결하면 그 일정을 그대로
   다룬다(지우기·옮기기).
5. **연결이 없어도 204다.** 두 번 눌러도 같다. `DELETE /lms/connection`과 같은 모양이다.
6. **읽지 못하는 토큰(암호화 키를 바꿈)은 거둘 수 없으니 지우기만 한다.** 500으로 끝내면 학생이
   영영 끊지 못한다.
7. **화면은 확인창을 거친다.** LearningX 해제와 같은 모양이고, 무엇이 남고 무엇이 사라지는지 문구로
   말한다("이미 넣은 일정은 캘린더에 그대로 남고, 새 일정은 다시 연결할 때까지 넣지 않아요").
8. **`calendar_auto_lms` 설정은 건드리지 않는다.** 연결이 없는 동안 동기화는 캘린더만 건너뛴다
   (이미 그렇게 돈다). 다시 연결하면 설정대로 바로 이어진다.

## 남은 것

- **진짜 Google에 거두는 것**은 네 계정으로 한 번 봐야 한다("합친 뒤 확인" 3번). 가짜 서버는 본문만
  받아 둔다.
- **이미 넣은 일정을 지울지**는 묻지 않았다(두지 않는 쪽). 지우고 싶다는 학생이 있으면 해제 전에
  `DELETE /calendar/events/{id}`를 돌리는 선택지를 확인창에 더할 수 있다.
- 탈퇴(`DELETE /me`)도 Google 쪽 권한을 거둬야 맞다. 지금은 토큰 행만 지운다 — 같은 `disconnect`를
  탈퇴 앞에 한 번 부르면 된다. 탈퇴 흐름을 건드리는 일이라 이번에는 넣지 않았다.

````text
### `DELETE /auth/google/tokens`

`204`. 캘린더 연결을 해제한다(F-06). 설정의 "연결 해제"가 부른다.

- **Google 쪽 권한도 거둔다**(`https://oauth2.googleapis.com/revoke`에 refresh token을 보낸다 — 그 승인 전체가 풀린다). 거두지 못해도(Google이 막힘) 저장한 토큰은 지운다. 못 거둔 권한은 학생이 Google 계정 설정에서 직접 거둘 수 있다. 이미 풀린 토큰(Google이 400)은 성공으로 본다
- 저장한 토큰(`oauth_tokens`)을 지운다. 그 뒤 `GET /me`의 `calendar_connected`는 false이고, 캘린더가 필요한 API는 `409 CALENDAR_NOT_CONNECTED`(`not_connected`)다
````

#### `api/tests/test_calendar_disconnect.py`

```python
"""캘린더 연결 해제 (API 4장 `DELETE /auth/google/tokens`, F-06). Google 호출은 respx로 가로챈다.

보는 것: Google 쪽 권한을 거두고 저장한 토큰을 지운다, Google이 막혀도 토큰은 지운다, 이미 풀린
토큰(400)은 성공으로 본다, 연결이 없어도 204다. SQL은 test_calendar_disconnect_db.py가 본다.
"""

from collections.abc import Iterator
from datetime import UTC, datetime, timedelta

import httpx
import pytest
import respx
from fastapi.testclient import TestClient

from app.config import Settings, get_settings
from app.crypto import encrypt
from app.main import create_app
from app.repositories.calendar import GoogleTokens, get_calendar_repo
from tests.conftest import USER_ID, make_token

TOKENS = "/api/v1/auth/google/tokens"
REVOKE_URL = "https://oauth.test/revoke"
NOW = datetime(2026, 10, 19, 0, 0, tzinfo=UTC)


class FakeCalendarRepository:
    """토큰 행 하나만 흉내 낸다."""

    def __init__(self, key: str, *, connected: bool = True) -> None:
        self.tokens_row: GoogleTokens | None = (
            GoogleTokens(
                encrypt("access-1", key), encrypt("refresh-1", key), NOW + timedelta(minutes=30)
            )
            if connected
            else None
        )
        self.deleted: list[str] = []

    async def tokens(self, user_id: str) -> GoogleTokens | None:
        return self.tokens_row if user_id == USER_ID else None

    async def delete_tokens(self, user_id: str) -> bool:
        self.deleted.append(user_id)
        had = self.tokens_row is not None
        self.tokens_row = None
        return had


@pytest.fixture
def calendar(settings: Settings) -> FakeCalendarRepository:
    return FakeCalendarRepository(settings.token_encryption_key)


@pytest.fixture
def client(settings: Settings, calendar: FakeCalendarRepository) -> Iterator[TestClient]:
    tuned = settings.model_copy(update={"google_revoke_url": REVOKE_URL})
    app = create_app(tuned)
    app.dependency_overrides[get_settings] = lambda: tuned
    app.dependency_overrides[get_calendar_repo] = lambda: calendar
    with TestClient(app) as test_client:
        yield test_client


@pytest.fixture
def auth() -> dict[str, str]:
    return {"Authorization": f"Bearer {make_token()}"}


def test_disconnect_requires_login(client: TestClient) -> None:
    assert client.delete(TOKENS).status_code == 401


@respx.mock
def test_disconnect_revokes_at_google_and_forgets_the_tokens(
    client: TestClient, auth: dict[str, str], calendar: FakeCalendarRepository
) -> None:
    revoke = respx.post(REVOKE_URL).mock(return_value=httpx.Response(200, json={}))
    response = client.delete(TOKENS, headers=auth)
    assert response.status_code == 204 and response.content == b""
    assert revoke.called
    assert (
        revoke.calls.last.request.content == b"token=refresh-1"
    )  # refresh token으로 승인 전체를 거둔다
    assert calendar.deleted == [USER_ID] and calendar.tokens_row is None


@respx.mock
def test_tokens_are_forgotten_even_when_google_is_down(
    client: TestClient,
    auth: dict[str, str],
    calendar: FakeCalendarRepository,
```
