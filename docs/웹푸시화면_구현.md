# 웹 푸시 2부 — 서비스 워커와 "이 브라우저에서 알림 받기"

> 📝 기준: API 명세 v0.4 10장 · PRD v0.9 F-33 · 2026-10-18

구독을 만들어 서버에 올리고, 푸시가 오면 알림을 띄우고, 누르면 그 화면으로 간다.

## 정한 것

1. **계정 스위치와 기기 구독을 두 줄로 나눴다.** 설정의 "푸시 알림 켜기"는 계정 전체 값이고
   (서버가 보낼 때 본다), 새로 넣은 "이 브라우저에서 알림 받기"는 **그 브라우저 하나**의 구독이다.
   하나로 묶으면 노트북에서 켠 사람이 휴대폰에서도 "켜짐"으로 보는데 알림은 오지 않는다.
2. **기기를 켤 때 계정 스위치를 대신 켜 주지 않는다.** 일부러 꺼 둔 값을 말없이 뒤집는 셈이다.
   대신 기기 줄 아래에 "위의 푸시 알림 켜기가 꺼져 있어요"를 띄운다(알림함 배너에서 켠 경우에는
   안내를 토스트로 준다 — 그 화면에는 계정 스위치가 없다).
3. **권한은 누른 그 자리에서만 묻는다.** 화면을 열자마자 묻는 사이트는 브라우저가 다음부터 아예
   막는다(크롬은 조용히 거절한다). 그래서 `Notification.requestPermission()`은 토글·배너 단추를
   누른 직후에만 부른다.
4. **서버에 올리지 못하면 브라우저 구독을 도로 지운다.** "켜짐"인데 아무것도 오지 않는 쪽이
   꺼진 쪽보다 나쁘다. 켜짐의 뜻을 "서버가 이 브라우저를 안다"로 못 박았다.
5. **끌 때는 브라우저에서 먼저 지우고 서버에 `DELETE`를 보낸다.** 서버 요청이 실패해도 브라우저는
   이미 구독이 없으니 알림이 오지 않고, 서버에 남은 주소는 다음 발송에서 404·410으로 스스로
   지워진다(명세 10장). 반대 순서면 "지웠는데 계속 오는" 상태가 생긴다.
6. **앱을 열 때 이미 있는 구독을 다시 올린다.** 브라우저는 구독 주소를 스스로 바꾸기도 하고
   (`pushsubscriptionchange`), 같은 브라우저로 다른 사람이 로그인하면 서버의 주인이 어긋난다.
   올리기는 같은 주소면 키만 갱신하는 덮어쓰기라 몇 번을 해도 안전하다.
   `pushsubscriptionchange`를 서비스 워커에서 직접 처리하지 않은 까닭은, 워커에는 **로그인 토큰이
   없어** 구독을 올릴 수 없기 때문이다. 앱을 여는 쪽이 토큰을 들고 있다.
7. **공개 키가 없으면 켜는 자리를 아예 그리지 않는다.** 서버도 키가 없으면 푸시를 건너뛴다(1부).
   켤 수 없는 스위치를 보여 주면 "눌렀는데 아무 일도 안 난다"가 된다. 알림함은 그대로 쓴다.
8. **알림을 누르면 열어 둔 탭을 쓴다.** 누를 때마다 새 창이 생기면 금세 탭이 쌓인다. 탭을 맡지
   못해 `navigate`가 거절되면 그때만 새 창을 연다.
9. **서비스 워커는 캐시를 하지 않는다.** 우리 화면은 로그인한 사람의 최신 자료만 보여 준다.
   오프라인 캐시는 "지난 주 마감"을 보여 줄 위험만 있다.
10. **푸시 본문은 믿지 않고 한 번 걸러서 쓴다.** `url`이 `/`로 시작할 때만 쓰고 아니면 홈으로,
    제목이 없으면 "새 알림이 있어요"로 바꿔 알림함으로 보낸다. 본문을 만드는 쪽은 우리 서버지만,
    서비스 워커가 받는 것은 **바깥에서 들어온 바이트**다.
11. **`tag`는 알림 id로 둔다.** 같은 알림이 두 번 와도 알림 서랍에 하나만 쌓인다.
12. **배너는 알림함에만 둔다.** 알림함을 보러 왔다는 것은 알림을 기다린다는 뜻이다. "나중에"로
    접으면 이번 방문 동안만 숨는다(탭을 닫으면 다시 보인다) — 영영 숨기면 켤 길이 설정뿐이다.
13. **토글 조각을 밖으로 뺐다.** 알림 설정 안에 있던 스위치를 `components/Toggle.tsx`로 옮겨
    두 곳이 같은 모양을 쓴다(새 색·새 모양을 만들지 않았다).
14. **목 모드는 권한창과 푸시 서비스를 흉내만 낸다.** 목으로 화면을 볼 때 브라우저 권한창이 뜨면
    화면만 보려던 사람이 막힌다. 구독은 메모리에만 둬서 다른 목 데이터와 같게 했다.

## 합친 뒤 확인

````text
web> npm run dev  (web/.env.local에 NEXT_PUBLIC_VAPID_PUBLIC_KEY가 있어야 한다)

1. 설정 → 알림에 "이 브라우저에서 알림 받기" 줄이 보인다. 켜면 브라우저 권한창이 뜬다.
2. 허용하면 스위치가 켜지고, 알림함 맨 위의 "알림 켜기" 배너가 사라진다.
3. 끄면 스위치가 돌아간다. 크롬 주소창 왼쪽 자물쇠에서 알림을 "차단"으로 바꾸면 스위치가 잠기고
   되돌리는 법이 안내로 뜬다.

실제 푸시 한 통을 눈으로 보고 싶으면(api/.env에 INTERNAL_API_KEY가 있어야 한다):
  보낼 때가 된 알림이 있어야 한다. 그 뒤
  curl -X POST http://localhost:8000/api/v1/internal/jobs/send-notifications -H "X-Internal-Key: <키>"
  응답의 pushed가 1 이상이면 바탕화면에 알림이 뜬다. 누르면 그 화면이 열린다.
````

## 검토에서 고친 것

| 본 것 | 고친 것 |

| M8이 살아남았다 — 구독한 뒤 배너가 사라지는지 **보는 자리가 없었다**(켤 때 숨기는 것은 화면 안쪽 상태라 조건이 틀려도 그 자리에서는 티가 안 난다) | 켠 채로 알림함에 다시 들어가 배너 수를 세는 단계를 더했다 |

| 스위치 모양이 알림 설정 파일 안에만 있었다 | `components/Toggle.tsx`로 빼서 두 곳이 같은 것을 쓴다 |

| 공개 키의 base64 패딩을 채우는 줄이 돌연변이를 만들어도 안 깨졌다 | `atob`가 패딩 없이도 읽기 때문이다. 줄은 남겨 두고(잘못 붙여 넣은 키 방어) 변이를 `-`·`_` 변환 제거로 바꿔 다시 쟀다 |

## 남은 것

- **iOS Safari**는 "홈 화면에 추가"한 뒤에만 웹 푸시를 받는다. 지금은 지원 여부만 보고 줄을 숨기므로
  아이폰 사파리에서는 줄이 보이지 않는다. 안내 문구를 둘지는 기기를 놓고 보며 정하자.
- **알림 아이콘**(`icon`·`badge`)은 넣지 않았다. `public/`에 쓸 PNG가 없다 — 브라우저 기본 아이콘이 뜬다.
- **실제 푸시 서비스로 끝까지** 보낸 확인은 못 했다(샌드박스에 FCM이 없다). 서버 쪽 암호화는 1부에서
  RFC 8291 복호화로, 브라우저 쪽은 이번에 가짜 `subscribe` 하나만 두고 나머지를 다 돌렸다. 둘을 잇는
  확인은 네 PC에서 "합친 뒤 확인"의 curl 한 줄로 한다.
- **web 자동 시험이 레포에 없다.** 이번 확인은 샌드박스 스크립트(Playwright·node)다. 화면 회귀를
  CI에서 잡으려면 시험 도구를 web에 붙이는 일이 따로 필요하다 — 지금은 범위 밖이다.
- **알림 종류별 끄기**는 서버에서만 본다(`muted_notification_types`). 브라우저에는 그대로 뜬다 —
  서버가 그 종류를 아예 안 보내기 때문에 맞다.

```js
// 웹 푸시 서비스 워커 (F-33, API 명세 10장). 번들을 타지 않는 평범한 자바스크립트다 —
// public/에 그대로 놓여 /sw.js 주소로 나가고, 그래야 범위(scope)가 사이트 전체가 된다.
//
// 하는 일은 둘뿐이다: 푸시를 받아 알림을 띄우고, 누르면 그 화면으로 보낸다.
// 캐시·오프라인은 하지 않는다 — 우리 화면은 로그인한 사용자의 최신 자료만 보여 준다.

// 받은 본문이 우리 모양이 아니면(푸시 서비스 점검 메시지 등) 알림함으로 보낸다
const FALLBACK = { title: "새 알림이 있어요", body: null, url: "/notifications", notification_id: "" };

function payloadOf(event) {
  if (!event.data) return FALLBACK;
  try {
    const data = event.data.json();
    if (!data || typeof data.title !== "string") return FALLBACK;
    return {
      title: data.title,
      body: typeof data.body === "string" ? data.body : null,
      url: typeof data.url === "string" && data.url.startsWith("/") ? data.url : "/",
      notification_id: typeof data.notification_id === "string" ? data.notification_id : "",
      type: typeof data.type === "string" ? data.type : "",
    };
  } catch {
    return FALLBACK;
  }
}

// 설치하자마자 새 워커가 일한다. 고친 워커가 다음 방문까지 기다리면 사용자는 옛 동작을 본다
self.addEventListener("install", () => self.skipWaiting());
self.addEventListener("activate", (event) => event.waitUntil(self.clients.claim()));

self.addEventListener("push", (event) => {
  const payload = payloadOf(event);
  // tag를 알림 id로 두면 같은 알림이 두 번 와도 하나만 쌓인다(id가 없으면 겹치지 않게 둔다)
  event.waitUntil(
    self.registration.showNotification(payload.title, {
      body: payload.body ?? undefined,
      data: { url: payload.url, notification_id: payload.notification_id },
      tag: payload.notification_id || undefined,
      lang: "ko",
    }),
  );
});

self.addEventListener("notificationclick", (event) => {
  event.notification.close();
  const url = (event.notification.data && event.notification.data.url) || "/";
  event.waitUntil(
    self.clients.matchAll({ type: "window", includeUncontrolled: true }).then((windows) => {
      // 이미 열어 둔 탭이 있으면 그 탭을 쓴다. 누를 때마다 새 창이 생기면 성가시다
      for (const client of windows) {
        if (new URL(client.url).origin !== self.location.origin) continue;
        return client.focus().then((focused) => {
          // navigate는 워커가 아직 그 탭을 맡지 않았으면 거절한다. 그때는 새 창으로 연다
          if (!focused.navigate) return self.clients.openWindow(url);
          return focused.navigate(url).catch(() => self.clients.openWindow(url));
        });
      }
      return self.clients.openWindow(url);
    }),
  );
});
```

```ts
import { USE_MOCKS } from "@/api/http";
import type { PushSubscriptionRequest } from "@/types/api";

// 브라우저 쪽 웹 푸시 (F-33, API 명세 10장). 화면은 `window`·`navigator`를 직접 만지지 않고
// 이 파일만 쓴다(web/CLAUDE.md). 서버로 보내는 일은 `api/pushClient.ts`가 한다.
//
// 공개 키가 없는 배포에서는 아무것도 보여 주지 않는다 — 서버도 키가 없으면 푸시를 건너뛰고
// 알림함에만 쌓는다(명세 10장). 목 모드는 브라우저 권한창을 띄우지 않고 흉내만 낸다.

export const VAPID_PUBLIC_KEY = process.env.NEXT_PUBLIC_VAPID_PUBLIC_KEY ?? "";

const SW_URL = "/sw.js";
const DISMISS_KEY = "unipivot.push.banner";

export type PushPermission = "default" | "granted" | "denied";

export interface PushState {
  supported: boolean; // 이 브라우저가 서비스 워커·푸시를 할 수 있나
  configured: boolean; // 공개 키가 설정에 있나
  permission: PushPermission;
  subscribed: boolean; // 이 브라우저가 지금 구독을 들고 있나
}

export const UNAVAILABLE: PushState = {
  supported: false,
  configured: false,
  permission: "default",
  subscribed: false,
};

// 목 모드의 가짜 구독. 메모리에만 있어 새로고침하면 초기화된다(다른 목 데이터와 같다)
let mockSubscription: PushSubscriptionRequest | null = null;

export function pushSupported(): boolean {
  if (USE_MOCKS) return true;
  return (
    typeof window !== "undefined" &&
    "serviceWorker" in navigator &&
    "PushManager" in window &&
    "Notification" in window
  );
}

function permissionNow(): PushPermission {
  if (USE_MOCKS) return mockSubscription ? "granted" : "default";
  if (typeof window === "undefined" || !("Notification" in window)) return "default";
  return Notification.permission as PushPermission;
}

/** base64url 공개 키를 `PushManager.subscribe()`가 받는 바이트로 바꾼다(패딩이 빠져 있다).
 *
 * 버퍼를 먼저 만들어 넘긴다 — `new Uint8Array(길이)`는 타입이 `ArrayBufferLike`여서
 * `applicationServerKey`(ArrayBuffer만 받는다)에 들어가지 않는다. */
function keyBytes(value: string): Uint8Array<ArrayBuffer> {
  const padded = value.replace(/-/g, "+").replace(/_/g, "/") + "=".repeat((4 - (value.length % 4)) % 4);
  const raw = atob(padded);
  const bytes = new Uint8Array(new ArrayBuffer(raw.length));
  for (let index = 0; index < raw.length; index += 1) bytes[index] = raw.charCodeAt(index);
  return bytes;
}

function base64url(buffer: ArrayBuffer | null): string {
  if (!buffer) return "";
  const bytes = new Uint8Array(buffer);
  let binary = "";
  bytes.forEach((byte) => {
    binary += String.fromCharCode(byte);
  });
  return btoa(binary).replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, "");
}

/** 사용자가 기기를 알아보게 적는 값(명세 10장, 200자 제한). 못 알아보면 보내지 않는다. */
export function deviceLabel(): string | undefined {
  if (USE_MOCKS) return "목 브라우저 / 미리보기";
  if (typeof navigator === "undefined") return undefined;
  const agent = navigator.userAgent;
  const browser =
    /Edg\//.test(agent) ? "Edge"
    : /OPR\//.test(agent) ? "Opera"
    : /Chrome\//.test(agent) ? "Chrome"
    : /Safari\//.test(agent) ? "Safari"
    : /Firefox\//.test(agent) ? "Firefox"
    : null;
  const system =
    /Windows/.test(agent) ? "Windows"
    : /Android/.test(agent) ? "Android"
    : /iPhone|iPad/.test(agent) ? "iOS"
    : /Mac OS X/.test(agent) ? "macOS"
    : /Linux/.test(agent) ? "Linux"
    : null;
  const label = [browser, system].filter(Boolean).join(" / ");
  return label ? label.slice(0, 200) : undefined;
}

async function registration(): Promise<ServiceWorkerRegistration> {
  await navigator.serviceWorker.register(SW_URL);
  return navigator.serviceWorker.ready;
}

/** 앱을 열 때 서비스 워커를 등록해 둔다. 실패해도 화면은 그대로 돈다(푸시만 안 온다). */
export async function ensureServiceWorker(): Promise<void> {
  if (USE_MOCKS || !pushSupported() || !VAPID_PUBLIC_KEY) return;
  try {
    await navigator.serviceWorker.register(SW_URL);
  } catch {
    // 등록에 실패하는 환경(비보안 출처, 사생활 보호 창)이 있다. 알림함은 그대로 쓸 수 있다
  }
}

function toRequest(subscription: PushSubscription): PushSubscriptionRequest {
  return {
    endpoint: subscription.endpoint,
    keys: {
      p256dh: base64url(subscription.getKey("p256dh")),
      auth: base64url(subscription.getKey("auth")),
    },
    user_agent: deviceLabel(),
  };
}

/** 지금 이 브라우저가 들고 있는 구독. 없으면 null이다. */
export async function currentSubscription(): Promise<PushSubscriptionRequest | null> {
  if (USE_MOCKS) return mockSubscription;
  if (!pushSupported() || !VAPID_PUBLIC_KEY || Notification.permission !== "granted") return null;
  try {
    const found = await (await registration()).pushManager.getSubscription();
    return found ? toRequest(found) : null;
  } catch {
    return null;
  }
}

export async function readState(): Promise<PushState> {
  const supported = pushSupported();
  const configured = Boolean(VAPID_PUBLIC_KEY);
  if (!supported || !configured) {
    return { supported, configured, permission: permissionNow(), subscribed: false };
  }
  return {
    supported,
    configured,
    permission: permissionNow(),
    subscribed: (await currentSubscription()) !== null,
  };
}

export class PushDeniedError extends Error {}

/**
 * 권한을 묻고 구독을 만든다. 이미 있으면 그것을 그대로 준다.
 *
 * 권한창은 사용자가 단추를 누른 그 자리에서만 띄운다 — 화면을 열자마자 묻는 사이트는
 * 브라우저가 다음부터 아예 막아 버린다.
 */
export async function subscribeHere(): Promise<PushSubscriptionRequest> {
  if (USE_MOCKS) {
    mockSubscription = {
      endpoint: `https://mock.push.example/${Math.random().toString(36).slice(2)}`,
      keys: { p256dh: "mock-p256dh", auth: "mock-auth" },
      user_agent: deviceLabel(),
    };
    return mockSubscription;
  }
  const granted = await Notification.requestPermission();
  if (granted !== "granted") throw new PushDeniedError(granted);
  const manager = (await registration()).pushManager;
  const found = await manager.getSubscription();
  if (found) return toRequest(found);
  const made = await manager.subscribe({
    userVisibleOnly: true, // 조용한 푸시는 크롬이 거절한다
    applicationServerKey: keyBytes(VAPID_PUBLIC_KEY),
  });
  return toRequest(made);
}

/** 이 브라우저의 구독을 지운다. 지운 주소를 돌려준다(서버에서도 지워야 한다). */
export async function unsubscribeHere(): Promise<string | null> {
  if (USE_MOCKS) {
    const endpoint = mockSubscription?.endpoint ?? null;
    mockSubscription = null;
    return endpoint;
  }
  if (!pushSupported()) return null;
  const found = await (await registration()).pushManager.getSubscription();
  if (!found) return null;
  const endpoint = found.endpoint;
  await found.unsubscribe();
  return endpoint;
}

/** 알림함 배너를 이번 방문 동안 접어 둔다(탭을 닫으면 다시 보인다). */
export function dismissBanner(): void {
  try {
    sessionStorage.setItem(DISMISS_KEY, "1");
  } catch {
    // 사생활 보호 창에서는 저장이 막힌다. 그러면 접힘이 안 남을 뿐이다
  }
}

export function bannerDismissed(): boolean {
  try {
    return sessionStorage.getItem(DISMISS_KEY) === "1";
  } catch {
    return false;
  }
}
```

```ts
    if (found) await savePushSubscription(found);
  } catch {
    // 올리지 못해도 화면은 그대로 돈다. 다음에 앱을 열 때 다시 맞춘다
  }
}

export default function usePushSubscription(): PushSubscriptionState {
  const [state, setState] = useState<PushState>(UNAVAILABLE);
  const [ready, setReady] = useState(false);
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const alive = useRef(true);

  useEffect(() => {
    alive.current = true;
    readState().then((found) => {
      if (!alive.current) return;
      setState(found);
      setReady(true);
    });
    return () => {
      alive.current = false;
    };
  }, []);

  const enable = useCallback(async () => {
    setBusy(true);
    setError(null);
    try {
      const subscription = await subscribeHere();
      try {
        await savePushSubscription(subscription);
      } catch (cause) {
        await unsubscribeHere().catch(() => null); // 서버가 모르는 구독은 남기지 않는다
        throw cause;
      }
      setState(await readState());
      return true;
    } catch (cause) {
      setState(await readState());
      setError(cause instanceof PushDeniedError ? DENIED_HELP : errorMessage(cause, SAVE_FAILED));
      return false;
    } finally {
      setBusy(false);
    }
  }, []);

  const disable = useCallback(async () => {
    setBusy(true);
    setError(null);
    try {
      const endpoint = await unsubscribeHere();
      // 브라우저에서는 이미 지웠다. 서버가 남아도 보낼 때 404·410으로 스스로 지운다(명세 10장)
      if (endpoint) await removePushSubscription(endpoint);
      setState(await readState());
      return true;
    } catch (cause) {
      setState(await readState());
      setError(errorMessage(cause, STOP_FAILED));
      return false;
    } finally {
      setBusy(false);
    }
  }, []);

  return { state, ready, busy, error, enable, disable };
}
```
