# 배포 준비 — api는 Cloud Run, web은 Vercel (`chore/deploy-cloudrun`)

> 📝 기준: PRD v0.9 9장(기술 스택·스케줄러)·12장·14장 · README "데모" 절 · `docs/데모_리허설.md` · api/CLAUDE.md
> 적용할 곳: main 위 새 브랜치. **api는 새 파일만**(배포 명령 `app/deploy/`, `Dockerfile`, 무시 목록 두 개, 시험 1개), **web은 `vercel.json`
> 하나**, 문서는 새 절차서(`docs/배포_절차.md`)와 9장 네 곳. 앱 코드·DB·API 계약은 안 바뀐다. 마이그레이션 없음.
> 사용자가 고른 것(10/23 오후): 데모 배포 준비 · api는 Cloud Run 서울·CPU 늘 켬 · web은 Vercel Hobby·함수 서울 · Supabase는 서울 ·
> Next.js 보안 권고는 다음 PR로 따로 · 학교 수집 허락 문의는 10/23에 보냄.

api를 Google Cloud Run(서울)에, web을 Vercel(함수 서울)에 올리는 데 필요한 것을 넣는다. 핵심은 **`uv run python -m app.deploy.cloudrun`** 명령
하나다 — 네 `api/.env`를 서버와 같은 방식(`Settings`)으로 읽어 비밀값은 Secret Manager로(표준 입력으로만, 화면에는 이름과 길이만), 나머지는
환경 변수로 넘기고 `gcloud run deploy --source .`로 올린다. 서버 안 스케줄러와 202 뒤에 이어 도는 일이 멈추지 않게 **인스턴스 최대 1개·CPU 늘
켬**으로 고정했다. 샌드박스는 Google API·Docker 레지스트리·Google Fonts에 닿지 않아(정책 차단) 실제 배포는 못 했고, 대신 이미지를 같은 구성의
대역 베이스로 빌드·실행하고, 만든 gcloud 인자를 진짜 gcloud(SDK 570)에 넣어 해석까지 확인했다.

## 1. 정한 것

| 고른 것 | 이유 · 버린 선택지 |
| --- | --- |
| api는 **Cloud Run 서울, CPU 늘 켬(인스턴스 기준 과금), 인스턴스 최대 1개**, 1 vCPU · 1GiB · 요청 300초 | 준비하기·포스터·강의자료 요약은 202로 답한 뒤 같은 프로세스에서 이어 돈다(`app/background.py`) — 요청 사이에 CPU를 끊는 기본값에서는 멈춘다. 서버 안 스케줄러는 워커가 하나여야 한다. 1 vCPU 아래는 요청 기준 과금만 된다(Cloud Run CPU 문서). 메모리는 300쪽 PDF를 메모리에서 읽어서 1GiB. 버린 것: 요청 기준 + 바깥 크론(202 작업을 바꾸는 코드 변경이 큼), Compute Engine VM(HTTPS·OS 업데이트를 직접) |
| **평소 최소 0 · 데모 기간 최소 1**. deploy는 `--min-instances`를 줄 때만 그 값을 바꾼다 | 1 vCPU·1GiB를 늘 켜면 한 달 기본 단가로 약 $47, 서울(Tier 2)은 더 비싸다(대략 $65 추정). 최소를 빼고 다시 올려도 데모 기간 설정이 꺼지지 않게 한다 |
| 바깥 크론은 **쓰지 않는다** | PRD 9장의 "배포 뒤에 다시 본다"(10/18)를 닫는다 — 인스턴스 하나·CPU 늘 켬이면 서버 안 스케줄러로 충분하다 |
| web은 **Vercel Hobby, 함수 지역 icn1**(`web/vercel.json`) | `/auth/callback`(서버 코드)이 Supabase(ap-northeast-2)·api와 같은 도시에서 돈다. Hobby는 함수 지역 하나를 고를 수 있다 |
| 배포를 **파이썬 명령**(`app.deploy.cloudrun`)으로 | 네 `api/.env`를 서버와 같은 `Settings`로 읽어서 값을 손으로 옮기지 않는다. PowerShell 파이프는 한글·줄바꿈이 섞이므로 비밀값은 파이썬이 gcloud 표준 입력에 바이트 그대로 넘긴다(명령줄에 없음 — 셸 기록·프로세스 목록에 안 남는다). 화면에는 이름과 길이만. 버린 것: 콘솔에서 손으로, 비밀값을 평범한 환경 변수로 |
| 비밀값은 **받아서 비교하고 바뀐 것만** 새 버전으로 | 버전마다 요금이 붙는다. gcloud는 값을 끝 줄바꿈 없이 내보낸다(SDK 소스의 출력 형식 `terminator=""`) |
| 설정 필드를 **넷으로 나눈다**: 그대로 넘김·비밀값·배포에서 정함(CORS·스케줄러)·기본값(시험용 주소·`API_PREFIX`) | 로컬 `.env`가 녹화 응답·가짜 저장소를 가리켜도 서버는 진짜 주소를 쓴다. 새 설정을 더하면 분류하지 않은 필드를 시험이 잡는다 |
| 검사는 **서버가 갖게 될 값으로** | 로컬 가짜 저장소 주소(`SUPABASE_STORAGE_BASE`)가 있으면 로컬 값으로는 통과해도 서버는 다른 주소를 쓴다 |
| DB 주소는 **로컬·직접 연결(`db.<ref>.supabase.co`)을 거절** | Supabase 직접 연결은 IPv6 주소다(Supabase 문서). Session pooler로 바꾸라고 안내한다 |
| 웹 출처는 **끝 /를 떼고 경로·http·와일드카드를 거절** | 컨테이너에서 확인: CORS는 글자 그대로 비교해서 `…vercel.app/`로 넣으면 모든 요청이 400이다 |
| `Dockerfile`: `python:3.12-slim` + uv 0.11.32 고정, `uv sync --locked --no-dev`, 루트 아닌 사용자, 워커 하나, `$PORT`, `--forwarded-allow-ips '*'` | 앞단이 127.0.0.1이 아니면(Cloud Run) 이 플래그 없이 리다이렉트가 `http://`로 나간다(브리지 네트워크로 확인). `--locked`는 `uv.lock`이 어긋나면 빌드를 멈춘다 |
| 무시 목록 두 개(`.gcloudignore`·`.dockerignore`)에 `.env`, 명령이 그 줄을 확인. `.gcloudignore`는 허용 목록(`/*` 뒤에 필요한 것만 염) | `.env`가 Cloud Build로 올라가거나 이미지에 들어가면 서버가 로컬 비밀값을 읽는다. 허용 목록이면 api 폴더에 놓인 다른 파일(키 JSON·저장한 응답)도 올라가지 않는다 |
| Gemini는 서비스 계정 `roles/aiplatform.user`, 비밀값은 `roles/secretmanager.secretAccessor`, 소스 빌드 계정은 `roles/run.builder` | 키 파일 없이 같은 프로젝트의 권한으로 부른다. 소스 배포는 Compute 기본 계정으로 빌드한다(Cloud Run 문서) |
| Next.js 16.4.0 보안 권고(critical 3건)는 **다음 PR**, web은 그 PR을 합친 뒤 올린다 | 빌드 출력이 에이전트에게 업그레이드 명령을 돌리라고 했지만 돌리지 않고 물었다. 우리 코드는 `next/image`·Server Actions·`use cache`를 쓰지 않지만 공개 주소에 그대로 올리지 않는다 |
| PRD 12장·14장 학교 수집 허락 문의 날짜를 **10/23**으로 | 10/9에 보냈는지 확인되지 않았고, 10/23에 캡스톤 문의처로 보냈다(네 답) |

## 3. 합친 뒤 확인 (네 PC)

실제 배포는 `docs/배포_절차.md`를 따른다. **web(Vercel)은 Next.js 보안 업데이트 PR을 합친 뒤**에 올린다. 지금은 아무것도 바꾸지 않는 미리
보기로 네 `api/.env`가 배포할 수 있는 상태인지만 본다.

```powershell
git checkout main
git pull
cd api
uv run python -m app.deploy.cloudrun deploy --web-origin https://example-check.vercel.app --dry-run
```

예상 출력(값은 없고 이름과 길이만이라 채팅에 붙여도 된다):

```text
프로젝트 <네 프로젝트 ID> · 지역 asia-northeast3 · 서비스 unipivot-api
서비스 계정 unipivot-api@<네 프로젝트 ID>.iam.gserviceaccount.com
웹 주소(CORS) https://example-check.vercel.app
인스턴스 최대 1개 · CPU 늘 켬 · 최소 지금 값 그대로(처음이면 0)
비밀값 DATABASE_URL(…자), TOKEN_ENCRYPTION_KEY(44자), SUPABASE_SECRET_KEY(…자), …
환경 변수 SUPABASE_URL, SUPABASE_STORAGE_BUCKET, GOOGLE_CLOUD_PROJECT, …, CORS_ORIGINS, SCHEDULER_ENABLED
(알림: … — 빠지는 기능이 있으면 줄마다 하나)
(바꾸지 않음) gcloud run deploy unipivot-api --project=… --region=asia-northeast3 --source=. … --quiet
```

- `배포하지 않았어요. 고칠 것:`이 나오면 그 줄대로 `api/.env`를 고친다(가장 흔한 것: `DATABASE_URL`이 직접 연결 → Supabase Connect의 Session pooler).
- `알림: 로컬 .env의 SCHEDULER_ENABLED가 true예요`가 나오면, 배포한 뒤에는 로컬을 false로 둔다.
- GCP 설정(`setup`, 절차서 2장)은 지금 해도 된다 — 아무것도 공개되지 않는다.

## 4. 구조

```text
api/
  app/deploy/plan.py      계산만: 설정 분류, 검사(서버가 가질 값으로), 웹 출처 정규화, 환경 변수 파일, gcloud run deploy 인자
  app/deploy/cloudrun.py  gcloud 부르기: setup(API·서비스 계정·권한), deploy(로그인 확인 → 비밀값 맞추기 → 올리기 → 주소), --dry-run
  Dockerfile              python:3.12-slim + uv(고정) → uv sync --locked → 루트 아닌 사용자 → uvicorn 워커 하나, $PORT
  .gcloudignore           Cloud Build로 올리는 것만 적은 허용 목록(Dockerfile·pyproject.toml·uv.lock·.python-version·.dockerignore·app/)
  .dockerignore           이미지에 넣지 않는 것(같은 목록, Docker 문법)
web/vercel.json           함수 지역 icn1
docs/배포_절차.md          처음 한 번(1~6장)과 다시 올리기·되돌리기·비용·막힐 때(7~9장)
```

deploy 순서: `api/.env` → `Settings` → 검사(막히면 gcloud를 부르지 않고 고칠 것만 찍고 끝) → 계획 찍기 → `gcloud auth list` → 비밀값마다
`secrets describe` → 없으면 `create`, 있으면 `versions access latest`로 받아 비교 → 다르면 `versions add`(값은 늘 표준 입력) → 임시 폴더에
`env.yaml`(비밀 아님, 값마다 JSON 문자열) → `gcloud run deploy`(진행을 그대로 보여 줌) → 임시 폴더 지움 → `run services describe`로 주소 →
Vercel에 넣을 값 찍기.

배포 서버의 설정:

| 나눔 | 필드 | 배포 서버 |
| --- | --- | --- |
| 비밀값(Secret Manager) | `DATABASE_URL`·`TOKEN_ENCRYPTION_KEY`·`SUPABASE_SECRET_KEY`(필수), `SUPABASE_JWT_SECRET`·`GOOGLE_OAUTH_CLIENT_SECRET`·`VAPID_PRIVATE_KEY`·`YOUTH_API_KEY`·`INTERNAL_API_KEY`(있으면) | `unipivot-…` 비밀값의 latest |
| 그대로 넘김 | `SUPABASE_URL`·버킷·`GOOGLE_CLOUD_PROJECT`·지역·모델 다섯·상한 세 개·`GOOGLE_OAUTH_CLIENT_ID`·`VAPID_SUBJECT` | 로컬과 같다(비면 안 넘김 = 기본값) |
| 배포에서 정함 | `CORS_ORIGINS` = `--web-origin`들(JSON 목록), `SCHEDULER_ENABLED` = true | |
| 기본값 | `LMS_API_BASE`·`SUPABASE_STORAGE_BASE`·`GOOGLE_TOKEN_URL`·`GOOGLE_REVOKE_URL`·`GOOGLE_CALENDAR_API_BASE`·`API_PREFIX` | 진짜 주소. 로컬 값이 다르면 미리보기에 이름을 찍는다 |

## 5. 확인한 것

| 무엇 | 어떻게 | 결과 |
| --- | --- | --- |
| api 시험 | CI처럼 새 DB에 auth 흉내·마이그레이션·스키마 점검 후 전체 / DB 없이 전체 | 1796 passed / 1404 passed·392 skipped |
| 검사 도구 | ruff check · ruff format --check | 통과 |
| web | typecheck, `next build` 목·실제 모드 | 통과(글꼴은 샌드박스 대역 — Google Fonts가 막혀 있다) |
| 이미지 빌드 | 실제 `Dockerfile`, 베이스는 대역(공식 레지스트리가 막혀 있어 같은 uv 0.11.32와 CPython 3.12를 `/usr/local`에 둔 rootfs) | 통과. uid 10001로 돈다 |
| 이미지에 안 들어가는 것 | 가짜 `.env`·`.env.local`·`tests`·`__pycache__`를 둔 사본으로 빌드 | 하나도 없고, 안에서 `Settings().database_url`이 빈 값 |
| 확장 모듈이 바라는 라이브러리 | 이미지 안 `.venv`의 `.so` 전부 `ldd` | glibc 계열 + `libz.so.1`·`libgcc_s.so.1`뿐(Debian slim 필수 패키지). 나머지는 wheel 안에 있다 — 대역이 문제를 가릴 여지가 작다 |
| 뜨기·끄기 | `PORT=8123`, `SCHEDULER_ENABLED=true`, 로컬 DB | 약 2초에 `/health` ok, "스케줄러를 켰어요" 로그, 알림 발송 한 번, `docker stop` 0.7초에 정상 종료(코드 0) |
| `PORT`가 없을 때 | 브리지 네트워크 `-p 8125:8080` | 8080으로 뜬다 |
| CORS | `CORS_ORIGINS=["https://…vercel.app"]` | 그 출처는 200, 끝에 /를 붙인 출처는 400 |
| 앞단 https | 브리지 네트워크(요청이 172.17.0.1에서 옴), `X-Forwarded-Proto: https` | 플래그 있음 → `Location: https://…`, 없음 → `http://…` |

## 7. 검토에서 고친 것

독립 검토(읽기만 하는 별도 에이전트)를 두 번 돌렸다. 첫 번째는 두 시간 가까이 응답이 없어 멈췄고, 시간·명령 제한을 걸어 다시 돌린 두 번째가 보고했다.
높음 등급은 없었고, gcloud 인자·Windows 동작·비밀값·Dockerfile·설정 분류는 직접 확인해 문제없다고 했다. 지적 12건 중 이렇게 처리했다.

````python
def normalize_origins(raw: list[str]) -> tuple[tuple[str, ...], list[str]]:
    """웹 주소를 CORS 출처 모양(https://호스트)으로 맞춘다. 끝의 /는 떼고, 경로·쿼리가 있으면 막는다.

    CORS는 출처를 글자 그대로 비교한다 — 끝에 /가 붙거나 경로가 들어가면 모든 요청이 막힌다.
    """
    origins: list[str] = []
    problems: list[str] = []
    for value in raw:
        text = value.strip().rstrip("/")
        try:
            parts = urlsplit(text)
        except ValueError:
            parts = None
        if (
            parts is None
            or parts.scheme.lower() != "https"
            or not parts.hostname
            or parts.username is not None
            or parts.path
            or parts.query
            or parts.fragment
            or "*" in text
        ):
            problems.append(
                f"웹 주소가 출처 모양이 아니에요: {text or '(빈 값)'}. "
                "https://<프로젝트>.vercel.app처럼 경로 없이 넣으세요"
            )
            continue
        origin = f"https://{parts.netloc.lower()}"
        if origin not in origins:
            origins.append(origin)
    if not raw:
        problems.append("--web-origin으로 웹 주소를 넣어 주세요(https://<프로젝트>.vercel.app)")
    return tuple(origins), problems


def database_problem(url: str) -> str | None:
    """배포 서버가 닿을 수 있는 DB 주소인지. 값은 보여 주지 않는다."""
    if not url.strip():
        return "DATABASE_URL이 비어 있어요(api/.env)"
    try:
        hosts = conninfo_to_dict(url).get("host") or ""
    except Exception:
        return "DATABASE_URL을 읽지 못했어요(값은 보여 주지 않음). Supabase 대시보드 Connect에서 다시 복사하세요"
    names = [host.strip().lower() for host in str(hosts).split(",")]
    if not any(names) or any(
        not name or name.startswith("/") or name in _LOCAL_HOSTS for name in names
    ):
        return (
            "DATABASE_URL이 이 컴퓨터의 DB를 가리켜요. 배포 서버는 Supabase DB에 붙어야 해요 — "
            "대시보드 Connect의 Session pooler 주소를 넣으세요"
        )
    if any(_DIRECT_DB_HOST.fullmatch(name) for name in names):
        return (
            "DATABASE_URL이 직접 연결(db.<ref>.supabase.co)이에요. 이 주소는 IPv6라 Cloud Run에서 닿지 "
            "않아요 — 대시보드 Connect의 Session pooler 주소(…pooler.supabase.com:5432)를 넣으세요"
        )
    return None

def defaults_differ(settings: Settings) -> list[str]:

def _env_text(value: object) -> str:
    if isinstance(value, bool):
        return "true" if value else "false"
    return str(value)


def build_plan(
    settings: Settings,
    origins: tuple[str, ...],
    *,
    region: str = REGION,
    service: str = SERVICE,
    min_instances: int | None = None,
) -> Plan:
    env = {
        name.upper(): _env_text(getattr(settings, name))
        for name in COPIED
        if _env_text(getattr(settings, name)).strip()
    }
    env["CORS_ORIGINS"] = json.dumps(list(origins))
    env["SCHEDULER_ENABLED"] = "true"
    secrets = tuple(
        (secret, getattr(settings, secret.field))
        for secret in SECRETS
        if getattr(settings, secret.field)
    )
    return Plan(
        project=settings.google_cloud_project.strip(),
        region=region,
        service=service,
        origins=origins,
        env=env,
        secrets=secrets,
        min_instances=min_instances,
    )

def env_file_text(env: dict[str, str]) -> str:
    """gcloud --env-vars-file에 줄 YAML. 값마다 JSON 문자열로 적는다(JSON은 YAML이다, 모두 ASCII)."""
    return "".join(f"{key}: {json.dumps(value)}\n" for key, value in env.items())


def secrets_flag(plan: Plan) -> str:

def deploy_args(plan: Plan, env_file: str) -> list[str]:

    `--min-instances`는 넣으라고 할 때만 붙인다. 안 붙이면 지금 값을 그대로 둔다 — 데모 기간(1)에 다시
    올리다가 평소(0)로 돌아가지 않게.
    """
    args = [
        "run",
        "deploy",
        plan.service,
        f"--project={plan.project}",
        f"--region={plan.region}",
        "--source=.",
        f"--service-account={plan.service_account}",
````

````python
"""Cloud Run에 api를 올린다(docs/배포_절차.md). **api 폴더에서** 돌린다.

    uv run python -m app.deploy.cloudrun setup                       # 처음 한 번: API·서비스 계정·권한
    uv run python -m app.deploy.cloudrun deploy --web-origin https://<웹 주소> [--min-instances 0|1]

둘 다 `--dry-run`을 붙이면 아무것도 바꾸지 않고 할 일만 찍는다. 설정은 `api/.env`에서 읽고(서버와 같은
방식), 비밀값은 Secret Manager로 보낸다. **값은 화면에 찍지 않는다**(이름과 길이만). gcloud에는 비밀값을
명령줄이 아니라 표준 입력으로 넘긴다 — 명령줄은 다른 프로그램과 셸 기록에 남는다.

gcloud는 `gcloud auth login`으로 로그인해 둔다(로컬 Gemini용 `application-default login`과 다르다).
"""

import argparse
import json
import os
import shutil
import subprocess
import sys
import tempfile
import time
from collections.abc import Callable, Sequence
from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

from app.config import Settings
from app.deploy import plan as deploy_plan
from app.deploy.plan import Plan
from app.runtime import utf8_output

# 배포에 올리는 폴더에 있어야 하는 것. 무시 목록 두 개가 없으면 .env가 Cloud Build로 같이 올라갈 수 있다
_REQUIRED_FILES = (
    "Dockerfile",
    "pyproject.toml",
    "uv.lock",
    ".python-version",
    ".dockerignore",
    ".gcloudignore",
)
_IGNORE_FILES = (".dockerignore", ".gcloudignore")
_BINDING_RETRIES = 6  # 새로 만든 서비스 계정이 IAM에 보이기까지 잠깐 걸린다
_BINDING_WAIT_SECONDS = 5.0


def _say(text: str) -> None:
    """gcloud 진행 출력과 순서가 섞이지 않게 바로 내보낸다."""
    print(text, flush=True)


class DeployError(Exception):
    """사람이 고쳐야 멈추는 실패. 문구는 무엇을 하면 되는지 쓴다."""


@dataclass(frozen=True)
class Result:
    code: int
    stdout: bytes = b""
    stderr: bytes = b""

    def error_text(self) -> str:
        """gcloud 오류의 마지막 몇 줄. gcloud 오류에는 비밀값이 들어가지 않는다(값은 표준 입력으로만 준다)."""
        lines = [
            line for line in self.stderr.decode("utf-8", "replace").splitlines() if line.strip()
        ]
        return "\n".join(lines[-4:]) or f"(gcloud 종료 코드 {self.code})"


class Runner(Protocol):
    def __call__(
        self, args: Sequence[str], *, input: bytes | None = None, capture: bool = True
    ) -> Result: ...


def gcloud_runner() -> Runner:
    """gcloud를 부른다. Windows에서는 gcloud.cmd를 찾는다. 묻는 창이 뜨지 않게 한다."""
    path = shutil.which("gcloud")
    if path is None:
        raise DeployError(
            "gcloud를 찾지 못했어요. Google Cloud CLI를 설치하고 PowerShell을 새로 연 뒤 다시 해 주세요"
        )
    # gcloud가 HTTP 본문(비밀값 포함)을 로그에 남기지 않게 한다
    env = {
        **os.environ,
        "CLOUDSDK_CORE_DISABLE_PROMPTS": "1",
        "CLOUDSDK_CORE_LOG_HTTP": "false",
        "CLOUDSDK_CORE_VERBOSITY": "warning",
    }

    def run(args: Sequence[str], *, input: bytes | None = None, capture: bool = True) -> Result:
        stdin = {"input": input} if input is not None else {"stdin": subprocess.DEVNULL}
        done = subprocess.run([path, *args], capture_output=capture, check=False, env=env, **stdin)
        return Result(done.returncode, done.stdout or b"", done.stderr or b"")

    return run


def _missing(result: Result) -> bool:
    """없어서 실패했는가(권한·네트워크 실패와 가른다)."""
    return b"NOT_FOUND" in result.stderr or b"FAILED_PRECONDITION" in result.stderr


def _must(result: Result, what: str) -> Result:
    if result.code != 0:
        raise DeployError(f"{what}에 실패했어요:\n{result.error_text()}")
    return result


def check_login(run: Runner) -> None:
    done = _must(run(["auth", "list", "--format=json"]), "gcloud 로그인 확인")
    try:
        accounts = json.loads(done.stdout or b"[]")
    except ValueError:
        accounts = []
    if not any(item.get("status") == "ACTIVE" for item in accounts if isinstance(item, dict)):
        raise DeployError("gcloud에 로그인돼 있지 않아요. gcloud auth login을 먼저 해 주세요")


def check_workdir(workdir: Path) -> None:
    missing = [name for name in _REQUIRED_FILES if not (workdir / name).is_file()]
    if missing or not (workdir / "app").is_dir():
        raise DeployError(
            f"api 폴더에서 돌려 주세요(없는 것: {', '.join(missing) or 'app/'}). "
            "cd api 뒤에 다시 해요"
        )
    for name in _IGNORE_FILES:
        lines = {line.strip() for line in (workdir / name).read_text(encoding="utf-8").splitlines()}
        if ".env" not in lines:
            raise DeployError(
                f"{name}에 .env 줄이 없어요. 그대로 올리면 비밀값 파일이 같이 올라가요"
            )


def sync_secrets(run: Runner, plan: Plan, out: Callable[[str], None]) -> None:
    """비밀값을 Secret Manager에 맞춘다. 같으면 그대로 두고, 다르면 새 버전을 더한다."""
    project = f"--project={plan.project}"
    for secret, value in plan.secrets:
        data = value.encode("utf-8")
        label = f"  {secret.env} → {secret.secret_id}"
        found = run(["secrets", "describe", secret.secret_id, project, "--format=json"])
        if found.code != 0:
            if not _missing(found):
                raise DeployError(f"{secret.secret_id}를 확인하지 못했어요:\n{found.error_text()}")
            _must(
                run(
                    [
                        "secrets",
                        "create",
                        secret.secret_id,
                        project,
                        "--replication-policy=automatic",
                        "--data-file=-",
                    ],
                    input=data,
                ),
                f"{secret.secret_id} 만들기",
            )
            out(f"{label}: 새로 만들었어요({len(value)}자)")
            continue
        latest = run(
            ["secrets", "versions", "access", "latest", f"--secret={secret.secret_id}", project]
        )
        if latest.code == 0 and latest.stdout == data:
            out(f"{label}: 그대로예요({len(value)}자)")
            continue
        if latest.code != 0 and not _missing(latest):
            raise DeployError(f"{secret.secret_id}의 값을 읽지 못했어요:\n{latest.error_text()}")
        _must(
            run(
                ["secrets", "versions", "add", secret.secret_id, project, "--data-file=-"],
                input=data,
            ),
            f"{secret.secret_id} 새 버전",
        )
        out(f"{label}: 새 값으로 바꿨어요({len(value)}자)")


def service_url(run: Runner, plan: Plan) -> str:
    done = _must(
        run(
            [
                "run",
                "services",
                "describe",
                plan.service,
                f"--project={plan.project}",
                f"--region={plan.region}",
                "--format=json",
            ]
        ),
        "서비스 주소 확인",
    )
    try:
        url = json.loads(done.stdout)["status"]["url"]
    except (ValueError, KeyError, TypeError):
        raise DeployError(
            "서비스 주소를 읽지 못했어요. Cloud Run 콘솔에서 주소를 확인하세요"
        ) from None
    return str(url)


def deploy(run: Runner, plan: Plan, out: Callable[[str], None]) -> str:
    """비밀값을 맞추고 소스를 올려 새 버전을 띄운다. 서비스 주소를 돌려준다."""
    check_login(run)
    out("비밀값(Secret Manager)")
    sync_secrets(run, plan, out)
    # 환경 변수 파일(비밀 아님)은 레포 밖 임시 폴더에 쓰고 끝나면 지운다
    with tempfile.TemporaryDirectory(prefix="unipivot-deploy-") as folder:
        env_file = Path(folder) / "env.yaml"
        env_file.write_text(deploy_plan.env_file_text(plan.env), encoding="utf-8")
        out("Cloud Run에 올려요(처음은 5~10분 걸려요. 아래는 gcloud가 찍는 진행이에요)")
        done = run(deploy_plan.deploy_args(plan, str(env_file)), capture=False)
    if done.code != 0:
        raise DeployError("gcloud run deploy가 실패했어요. 위에 gcloud가 찍은 오류를 보세요")
    return service_url(run, plan)


def _bind(
    run: Runner, project: str, member: str, role: str, sleep: Callable[[float], None]
) -> None:
    args = [
        "projects",
        "add-iam-policy-binding",
        project,
        f"--member={member}",
        f"--role={role}",
        "--condition=None",
        "--quiet",
    ]
    for attempt in range(_BINDING_RETRIES):
        done = run(args)
        if done.code == 0:
            return
        # 방금 만든 서비스 계정은 잠깐 "없다"고 나온다
        if b"does not exist" not in done.stderr or attempt == _BINDING_RETRIES - 1:
            raise DeployError(f"{role} 권한 주기에 실패했어요:\n{done.error_text()}")
        sleep(_BINDING_WAIT_SECONDS)

def _parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="python -m app.deploy.cloudrun", description=__doc__)
    commands = parser.add_subparsers(dest="command", required=True)
    setup_cmd = commands.add_parser("setup", help="처음 한 번: API·서비스 계정·권한")
    setup_cmd.add_argument("--dry-run", action="store_true", help="바꾸지 않고 할 일만 찍는다")
    deploy_cmd = commands.add_parser("deploy", help="비밀값을 맞추고 새 버전을 올린다")
    deploy_cmd.add_argument(
        "--web-origin",
        action="append",
        default=[],
        help="웹 주소(https://<프로젝트>.vercel.app). 여러 번 줄 수 있다",
    )
    deploy_cmd.add_argument(
        "--min-instances",
        type=int,
        choices=(0, 1),
        help="0: 쓸 때만 켠다(평소) · 1: 늘 켠다(데모 기간). 빼면 지금 값을 둔다",
    )
    deploy_cmd.add_argument("--region", default=deploy_plan.REGION)
    deploy_cmd.add_argument("--service", default=deploy_plan.SERVICE)
    deploy_cmd.add_argument("--dry-run", action="store_true", help="바꾸지 않고 할 일만 찍는다")
    return parser


def main(
    argv: Sequence[str] | None = None,
    *,
    settings: Settings | None = None,
    runner: Runner | None = None,
    workdir: Path | None = None,
    out: Callable[[str], None] = _say,
    sleep: Callable[[float], None] = time.sleep,
) -> int:
    args = _parser().parse_args(argv)
    settings = settings or Settings()
    workdir = workdir or Path.cwd()
    try:
        if args.command == "setup":
            project = settings.google_cloud_project.strip()
            if problem := deploy_plan.project_problem(project):
                raise DeployError(problem)
            if args.dry_run:
                out(f"(바꾸지 않음) 프로젝트 {project}")
                out(f"켤 API {', '.join(deploy_plan.APIS)}")
                out(
                    f"서비스 계정 {deploy_plan.service_account(project)}: {', '.join(deploy_plan.SERVICE_ACCOUNT_ROLES)}"
                )
                out(f"소스 빌드 계정({{번호}}-compute@…): {deploy_plan.BUILDER_ROLE}")
                return 0
            setup(runner or gcloud_runner(), project, out, sleep=sleep)
            return 0
        check_workdir(workdir)
        origins, found = deploy_plan.normalize_origins(args.web_origin)
        found += deploy_plan.target_problems(args.region, args.service)
        found += deploy_plan.problems(settings)
        if found:
            out("배포하지 않았어요. 고칠 것:")
            for problem in found:
                out(f"  - {problem}")
            return 2
        plan = deploy_plan.build_plan(
            settings,
            origins,
            region=args.region,
            service=args.service,
            min_instances=args.min_instances,
        )
        for line in describe(plan, settings):
            out(line)
        for warning in deploy_plan.warnings(settings):
            out(f"알림: {warning}")
        if args.dry_run:
            command = deploy_plan.deploy_args(plan, "<임시 폴더>/env.yaml")
            out("(바꾸지 않음) gcloud " + " ".join(command))
            return 0
        url = deploy(runner or gcloud_runner(), plan, out)
    except DeployError as error:
        out(f"멈췄어요: {error}")
        return 1
    out(f"api 주소: {url}")
    out(f'확인: {url}/health 를 열면 {{"status":"ok"}}가 보여요')
    # 배포 서버는 API_PREFIX를 기본값으로 쓴다(plan.DEFAULTS_ONLY)
    out(f"Vercel의 NEXT_PUBLIC_API_BASE_URL: {url}{Settings.model_fields['api_prefix'].default}")
    return 0


if __name__ == "__main__":
    utf8_output()
    sys.exit(main())
````

````python
        (tmp_path / name).write_text("x\n", encoding="utf-8")
    for name in (".dockerignore", ".gcloudignore"):
        (tmp_path / name).write_text(".venv\n.env\n", encoding="utf-8")
    (tmp_path / "app").mkdir()
    return tmp_path


def run_main(argv: list[str], **kwargs: object) -> tuple[int, list[str]]:
    lines: list[str] = []
    code = cloudrun.main(argv, out=lines.append, sleep=lambda _: None, **kwargs)  # type: ignore[arg-type]
    return code, lines

def test_the_server_reads_back_what_we_send(monkeypatch: pytest.MonkeyPatch) -> None:
    """환경 변수 이름이 틀리면 서버가 조용히 기본값을 쓴다. 보낸 값을 Settings로 다시 읽어 맞춰 본다."""

    for secret, value in plan.secrets:

    for secret in deploy_plan.SECRETS:

    assert served.cors_origins == [WEB, "https://www.example.com"]
    assert served.scheduler_enabled is True
    for field in deploy_plan.DEFAULTS_ONLY:

def test_deploy_end_to_end(workdir: Path) -> None:
    seen_env: dict[str, str] = {}

    def answer(call: list[str], _: bytes | None) -> Result:
        if call[:2] == ["run", "deploy"]:
            path = Path(
                next(arg for arg in call if arg.startswith("--env-vars-file=")).split("=", 1)[1]
            )
            seen_env["path"] = str(path)
            seen_env["text"] = path.read_text(encoding="utf-8")
            return Result(0)
        if call[:2] == ["secrets", "describe"]:
            return not_found()
        return described_url(call) or Result(0)

    fake = FakeGcloud(answer)
    code, lines = run_main(
        ["deploy", "--web-origin", WEB + "/", "--min-instances", "1"],
        settings=full_settings(api_prefix="/local-only"),  # 서버는 기본 경로를 쓴다
        runner=fake,
        workdir=workdir,
    )

    assert code == 0, lines
    deploy_call = fake.find("run", "deploy")[0]
    assert deploy_call[2] is False  # gcloud 진행을 그대로 보여 준다
    assert "--min-instances=1" in deploy_call[0]
    assert '"[\\"https://unipivot-demo.vercel.app\\"]"' in seen_env["text"]
    assert not Path(seen_env["path"]).exists()  # 끝나면 지운다
    assert f"Vercel의 NEXT_PUBLIC_API_BASE_URL: {URL}/api/v1" in lines
    output = "\n".join(lines) + "\n".join(" ".join(call) for call in fake.commands())
    assert leaked(output) == []
    # 순서: 비밀값 → 배포 → 주소
    order = [call[:2] for call in fake.commands()]
    assert order.index(["secrets", "create"]) < order.index(["run", "deploy"])
    assert order.index(["run", "deploy"]) < order.index(["run", "services"])

def setup_answer(
    *, account_exists: bool, flaky_binding: int = 0
) -> Callable[[list[str], bytes | None], Result]:
    remaining = {"flaky": flaky_binding}

    def answer(call: list[str], _: bytes | None) -> Result:
        if call[:3] == ["iam", "service-accounts", "describe"]:
            return Result(0) if account_exists else not_found("Unknown service account")
        if call[:2] == ["projects", "describe"]:
            return Result(0, json.dumps({"projectNumber": "987654321"}).encode())
        if call[:2] == ["projects", "add-iam-policy-binding"] and remaining["flaky"]:
            remaining["flaky"] -= 1
            return Result(
                1, stderr=b"ERROR: INVALID_ARGUMENT: Service account unipivot-api does not exist."
            )
        return Result(0)

    return answer
````

````markdown
# 배포 절차 — api는 Cloud Run, web은 Vercel

> 📝 기준: PRD v0.9 9장(기술 스택·스케줄러)·14장 · README "데모" 절 · `docs/데모_리허설.md`

> (`YOUR-PROJECT`처럼 영어 자리표시만 있다).

## 0. 한눈에

| | api | web |
| --- | --- | --- |
| 어디 | Google Cloud Run, 서울(`asia-northeast3`), 서비스 이름 `unipivot-api` | Vercel Hobby, 함수 지역 서울(`icn1`, `web/vercel.json`) |
| 올리는 법 | api 폴더에서 `uv run python -m app.deploy.cloudrun deploy …`(빌드는 Cloud Build가 한다 — PC에 Docker가 없어도 된다) | GitHub `main`에 합치면 Vercel이 빌드한다 |
| 비밀값 | Secret Manager. 명령이 `api/.env`에서 옮기고 화면에는 이름과 길이만 찍는다 | 없다(`NEXT_PUBLIC_…`은 브라우저에 그대로 보이는 값이다) |
| 고정한 것 | 인스턴스 **최대 1개**, **CPU 늘 켬**, 1 vCPU · 메모리 1GiB, 요청 300초 | Root Directory `web`, Production 주소만 쓴다 |

왜 이렇게 했나:

- **최대 1개**: 정기 작업은 서버 안 스케줄러가 돌린다(`app/scheduler.py`). 인스턴스가 둘이면 같은 알림이 두 번 나갈 수 있다.
  평소에는 1개지만, 새 버전을 올리는 동안은 새 인스턴스가 먼저 뜨고 옛 인스턴스가 꺼지기까지 잠깐 2개가 겹친다(최대 개수는 버전 단위다).
  그 사이에 보낼 알림이 있으면 같은 푸시가 두 번 갈 수 있다 — 알림을 많이 쌓아 둔 채로 올리지 않는다(예약은 중복돼도 안전하다).
- **CPU 늘 켬**(인스턴스 기준 과금): 준비하기·포스터 추출·강의자료 요약은 202로 답한 뒤 같은 서버에서 계속 돈다(`app/background.py`).
  Cloud Run 기본값(요청이 없으면 CPU를 끊는다)에서는 이 일들이 멈춘다. 1 vCPU 아래로는 이 방식을 쓸 수 없다.
- **서울**: Supabase(ap-northeast-2)·Vercel 함수(icn1)와 같은 도시다. LearningX·온통청년에도 국내 지역에서 붙는다.
- **Gemini는 서비스 계정 권한**으로 부른다(키 파일 없음). 로컬과 같은 `GOOGLE_CLOUD_PROJECT`에 배포한다.

## 1. 준비 (한 번)

- **Google Cloud CLI**를 설치하고(설치 뒤 PowerShell을 새로 연다) 로그인한다. 로컬 Gemini용 `application-default login`과는 다른 로그인이다.

  ```powershell
  gcloud auth login
  gcloud config set project YOUR-PROJECT-ID
  ```

  뒤의 `gcloud` 명령(6·7·8장)은 이 설정 프로젝트를 쓴다. `YOUR-PROJECT-ID`는 `api/.env`의 `GOOGLE_CLOUD_PROJECT`와 같은 값이다.

- **`api/.env`를 확인한다**. 배포 서버는 이 파일과 같은 값에서 출발한다(명령이 읽어서 옮긴다).
  - `DATABASE_URL` — Supabase 대시보드 **Connect > Session pooler** 주소(`…pooler.supabase.com:5432`)여야 한다.
    직접 연결(`db.<ref>.supabase.co`)은 IPv6 주소라 Cloud Run에서 닿지 않는다(명령이 막는다).
  - `GOOGLE_CLOUD_PROJECT` — Gemini를 부르는 프로젝트. 배포도 이 프로젝트에 한다.
  - `TOKEN_ENCRYPTION_KEY` — **로컬에서 쓰던 키 그대로**. 바꾸면 저장된 Google·LMS 토큰을 못 읽는다.
  - 나머지(`SUPABASE_SECRET_KEY`·`GOOGLE_OAUTH_CLIENT_ID/SECRET`·`VAPID_*`·`YOUTH_API_KEY`·`INTERNAL_API_KEY`)는 없으면 명령이 무엇이
    빠지는지 알려 준다. 시험용으로만 바꾸는 주소(`LMS_API_BASE`·`SUPABASE_STORAGE_BASE`·`GOOGLE_*_URL` 등)는 넘기지 않는다 — 배포 서버는
    진짜 주소(기본값)를 쓴다.
- **크레딧**: Cloud Run·Cloud Build·Secret Manager도 Gemini와 같은 무료 체험 크레딧에서 빠진다(8장 비용).

## 3. web을 Vercel에 (주소를 먼저 정한다)

> **Next.js 보안 업데이트 PR(16.4.0 → 16.4.2)을 합친 뒤에 한다.** 16.4.0에는 critical 보안 권고가 있어 공개 주소에 그대로 올리지 않는다.

1. vercel.com → **Add New → Project** → GitHub의 `unipivot` 저장소 **Import**
2. **Root Directory: `web`** (Framework는 Next.js로 저절로 잡힌다)
3. **Environment Variables**(Production): `web/.env.local`과 같은 값을 넣는다. API 주소는 4장 뒤에 넣는다.

   | 이름 | 값 |
   | --- | --- |
   | `NEXT_PUBLIC_USE_MOCKS` | `false` |
   | `NEXT_PUBLIC_SUPABASE_URL` | `web/.env.local`과 같다 |
   | `NEXT_PUBLIC_SUPABASE_ANON_KEY` | `web/.env.local`과 같다 |
   | `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | `web/.env.local`과 같다(서버의 `VAPID_PRIVATE_KEY`와 짝) |
   | `NEXT_PUBLIC_API_BASE_URL` | 4장 끝에 찍히는 값 |

   `NEXT_PUBLIC_…`은 빌드할 때 화면 코드에 박힌다. 바꾸면 **Deployments → 최신 → Redeploy**를 눌러야 반영된다.
4. **Deploy** → 주소 `https://YOUR-PROJECT.vercel.app`을 적어 둔다. 이 단계의 화면은 API 주소가 없어 오류 안내가 뜬다(정상).
5. **Settings → Functions → Function Region**이 Seoul(icn1)인지 본다(`web/vercel.json`이 정한다).

미리보기 배포 주소(`…-git-….vercel.app`)는 CORS·Supabase 허용 목록에 넣지 않는다 — 거기서는 로그인이 안 된다. 데모는 Production 주소만 쓴다.

## 4. api를 Cloud Run에

```powershell
cd api
uv run python -m app.deploy.cloudrun deploy --web-origin https://YOUR-PROJECT.vercel.app --dry-run
uv run python -m app.deploy.cloudrun deploy --web-origin https://YOUR-PROJECT.vercel.app --min-instances 0
```

- `--dry-run`은 무엇을 올릴지(비밀값 이름·길이, 환경 변수 이름, 빠지는 기능)만 찍는다. 고칠 것이 있으면 배포하지 않고 목록을 찍는다.
- 처음은 5~10분 걸린다(Cloud Build가 `api/Dockerfile`로 이미지를 만든다). 끝에 **api 주소**와 **Vercel에 넣을 값**이 찍힌다.
- 그 값을 Vercel의 `NEXT_PUBLIC_API_BASE_URL`에 넣고 **Redeploy**한다.
- 배포한 뒤에는 **로컬 `api/.env`의 `SCHEDULER_ENABLED`를 `false`로** 둔다. 같은 DB에 정기 작업이 두 번 돈다(명령이 알려 준다).
- 무엇이 올라가는지는 `api/.gcloudignore`가 정한다(`.env`·`.venv`·`tests`는 안 올라간다). 명령은 이 파일과 `api/.dockerignore`에
  `.env` 줄이 없으면 멈춘다.

## 5. Supabase·Google 설정

- **Supabase → Authentication → URL Configuration**
  - **Site URL**: `https://YOUR-PROJECT.vercel.app`
  - **Redirect URLs**에 `https://YOUR-PROJECT.vercel.app/auth/callback**`을 **더한다**(`http://localhost:3000/auth/callback**`은 그대로 둔다).
    캘린더 연결은 콜백 뒤에 `?connect=calendar&next=…`가 붙어서 끝의 `**`가 있어야 맞는다.
- **Google OAuth 클라이언트는 바꿀 것이 없다.** Google이 돌아오는 곳은 Supabase 주소(`https://<ref>.supabase.co/auth/v1/callback`)다.
  게시 상태가 테스트면 데모 계정이 테스트 사용자에 있어야 한다(`docs/데모_리허설.md` D-7).

## 7. 다시 올리기·되돌리기

- **코드를 다시 올릴 때**: `main`을 pull한 상태에서 4장의 deploy 명령을 다시 돈다. `--min-instances`를 빼면 지금 값을 그대로 둔다
  (데모 기간에 다시 올려도 꺼지지 않는다). 비밀값은 바뀐 것만 새 버전으로 올라간다.
- **비밀값을 바꿀 때**: `api/.env`를 고치고 deploy를 다시 돈다.
- **되돌리기**: Cloud Run 콘솔 → `unipivot-api` → 버전(Revisions)에서 이전 버전에 트래픽 100%. 명령으로는:

  ```powershell
  gcloud run revisions list --service unipivot-api --region asia-northeast3
  gcloud run services update-traffic unipivot-api --region asia-northeast3 --to-revisions REVISION_NAME=100
  ```

  주의:
  - 이렇게 고정하면 서비스가 "최신 버전을 따라가기"를 멈춘다. **고친 코드를 다시 올린(deploy) 뒤에는 꼭**
    `gcloud run services update-traffic unipivot-api --region asia-northeast3 --to-latest`를 돌린다.
    안 하면 deploy가 성공과 주소를 찍어도 새 버전은 트래픽 0%라 옛 코드가 계속 답한다.
  - 되돌려도 **비밀값은 돌아가지 않는다**(항상 최신 버전을 읽는다). 옛 버전은 자기 시절의 최소 인스턴스 값도 그대로 가진다.

`gcloud config get-value project`가 배포한 프로젝트가 아니면(1장) 두 명령 끝에 `--project YOUR-PROJECT-ID`를 붙인다. 무료 체험 크레딧이 다 되면
과금 계정을 올리기 전까지 서비스가 멈춘다(크레딧 만료일은 `docs/LLM_모델_선정.md`).

## 9. 막히면

| 보이는 것 | 이유 | 할 일 |
| --- | --- | --- |
| deploy가 빌드에서 `PERMISSION_DENIED` | 2장을 안 했거나 권한이 아직 퍼지는 중 | 2장을 다시 돌리고 2분 뒤 다시 |
| 로그에 Gemini `403 PERMISSION_DENIED` | 서비스 계정에 `roles/aiplatform.user`가 없다 | 2장 |
| 화면의 모든 요청이 CORS 오류 | `--web-origin`이 실제 주소와 다르다(미리보기 주소 등) | 맞는 주소로 4장을 다시 |
| 로그인 뒤 localhost나 엉뚱한 곳으로 간다 | Supabase Redirect URLs에 배포 주소가 없다 | 5장 |
| `/health`는 되는데 로그인한 요청이 503 | 로그인·DB 설정 | 시작할 때 찍힌 로그의 "설정 확인" 줄을 본다 |
| 다시 올렸는데 화면이 안 바뀐다 | 되돌리기(7장)로 트래픽을 옛 버전에 고정해 둔 채다 | `gcloud run services update-traffic unipivot-api --region asia-northeast3 --to-latest` |
| 로그에 `MaxClientsInSessionMode` | Supabase 세션 풀러의 연결 수 한도(무료는 보통 15)를 로컬 api·배포 서버·CLI가 합쳐 넘었다 | 쓰지 않는 로컬 api·CLI를 끈다. 계속되면 `DATABASE_URL`을 트랜잭션 풀러(포트 6543)로 바꿔 deploy를 다시(코드는 이미 대응한다) |
| 정기 작업 결과가 없다 | 최소 0이라 서버가 꺼져 있었다 | 데모 기간에는 최소 1(8장) |
| LearningX 동기화만 실패 | 학교 서버가 클라우드 주소를 막았을 수 있다 | 로그의 상태 코드를 보고, 안 되면 데모 노트북의 로컬 api로 보여 준다 |
````
