# 로그아웃 구현 (F-06, `feat/F-06-sign-out`)

> 📝 기준: PRD v0.9 F-06 · 이 문서의 9장(PRD 반영)
> 적용할 곳: `main`(d16d008) 위에 **창 초점 PR(docs/창초점_구현.md)을 합친 뒤**. 같은 트리에서 만들고 시험했다(겹치는 파일은 없지만 순서대로 쌓은 트리에서 패치를 만들었다).

설정에 로그아웃이 없어서, 이 기기에서 계정을 내려놓으려면 탈퇴밖에 없었다(10/20 포스터 원본 확인 때 드러났다). 설정 > 계정에 "로그아웃"을 더한다. 먼저 이 브라우저의 웹 푸시 구독을 지우고(서버에도 `DELETE /push/subscriptions`), 이 기기의 세션만 끝내고(Supabase `signOut({ scope: "local" })` — 이 세션의 갱신 토큰을 서버에서 거두고 쿠키를 지운다) 로그인 화면으로 가서 "로그아웃했어요."를 보여 준다. 다른 기기의 로그인과 저장한 데이터는 그대로다. 사용자가 고른 작업이고, 세부는 아래 "정한 것"이다.

| 값 | 결과 |
| --- | --- |
| 브랜치 | `feat/F-06-sign-out` |
| 파일 | 새 파일 1개(`web/src/components/SignOutSetting.tsx`), 고친 파일 5개(전부 web) |
| api·DB | 안 바뀜(새 엔드포인트 없음 — 있는 `DELETE /push/subscriptions`를 부른다, CI 1598 passed 그대로, 마이그레이션 없음) |
| web | `npm run typecheck`·`npm run build`(실제·목 모드) 통과 |
| 브라우저 | 실제 모드(가짜 GoTrue): 성공·푸시 구독 정리·Supabase 500·세션 갱신 실패·뒤로 가기·설정 다시 열기 · 목 모드 — 5장 |
| 되돌림 시험 | 6개 전부 브라우저 점검이 잡음 |

## 1. 정한 것

| 고른 것 | 이유 · 버린 선택지 |
| --- | --- |
| 이 기기만(`scope: "local"`) | 기본값 `global`은 다른 기기의 로그인까지 모두 끊는다. "이 기기에서 나가기"가 사용자가 기대하는 로그아웃이다. 모든 기기에서 나가기는 필요하면 따로 둔다 |
| API 엔드포인트를 만들지 않는다 | 세션은 Supabase Auth가 들고 있고(웹 CLAUDE.md "Supabase는 로그인과 세션 토큰에만"), 우리 API에는 세션 상태가 없다. ERD는 그대로, 명세는 10장 "브라우저 쪽"에 한 줄(아래 푸시) |
| 로그아웃 전에 이 브라우저의 푸시 구독을 지운다 | 안 그러면 로그아웃한 기기(공용 PC 등)로 그 사람의 알림(과목·자료·공고 이름)이 계속 간다. 같은 브라우저로 다른 사람이 로그인하면 남은 구독이 말없이 그 사람에게 넘어가기도 한다(검토). 브라우저 구독을 지우고, 토큰이 살아 있을 때 `DELETE /push/subscriptions`. 둘 다 3초까지만 기다리고 실패해도 로그아웃은 막지 않는다(브라우저 구독이 없어지면 서버는 보낼 때 410으로 스스로 지운다). 서비스 워커를 새로 등록하지는 않는다(`unsubscribeIfAny` — 푸시를 쓰지 않는 배포·브라우저에서 아무것도 남기지 않게) |
| 끝났는지는 **세션 쿠키가 남았는지**로 본다 | supabase-js는 로그아웃 요청이 500이거나 끊겨도 이 기기의 세션을 먼저 지우고 오류만 돌려준다 — 이때는 그대로 로그인 화면으로 간다(남아 봐야 모든 요청이 401). 반대로 만료된 로그인을 갱신하다 연결이 끊기면 세션을 지우지 않고 오류만 돌려준다(검토) — 쿠키(`sb-…-auth-token`)가 남았으면 그 자리에서 "로그아웃하지 못했어요. 인터넷 연결을 확인하고 다시 눌러 주세요." 그때 supabase-js가 갱신을 다시 해 보느라 25초쯤 걸려서 8초까지만 기다린다 |
| 로그인 화면으로 갈 때 기록을 바꾼다(`location.replace`) | 뒤로 가기를 누르면 개인 정보가 그려진 설정 화면이 돌아올 수 있었다(검토). 탈퇴 뒤 이동도 같이 바꿨다 |
| 버튼은 `busy` | 누른 뒤 페이지가 바뀌기 전까지 초점을 지킨다(web 규칙) |
| 자리: 설정 > 계정, 소득 동의 아래·탈퇴 위 | 되돌릴 수 있는 일(로그아웃)을 되돌릴 수 없는 일(탈퇴) 위에 둔다. 설명 "이 기기에서만 로그아웃해요. 저장한 정보는 그대로 남아요."로 탈퇴와 구분한다 |
| 로그인 화면 안내 `?notice=signed_out` | 탈퇴 안내(`deleted`)와 같은 자리. "로그아웃했어요. 다시 쓰려면 Google로 시작하기를 눌러 주세요."(버튼 이름과 같게, 검토) |
| 목 모드 | 목 푸시 구독만 지우고 로그인 화면으로 간다(목 상태는 새로고침으로 초기화된다) |

## 7. 검토에서 고친 것

새 에이전트(이 작업을 못 본)가 읽기만 해서 본 결과다. 미들웨어·서버 쿠키(없음), 메모리 상태(전체 새로고침), busy 규칙, 목 모드, 탈퇴와의 일관성은 문제없었다.

| 지적 | 처리 |
| --- | --- |
| 높음 — 로그아웃한 기기로 푸시가 계속 간다(공용 PC에서 과목·자료·공고 이름이 뜬다) | 로그아웃 전에 브라우저 구독을 지우고 `DELETE /push/subscriptions`. 명세 10장에 한 줄. 되돌림 시험 L4 |
| 중간 — 만료된 로그인을 갱신하다 연결이 끊기면 세션이 남는데 "로그아웃했어요"로 넘어간다 | 세션 쿠키가 남았는지 보고 남았으면 그 자리에서 알린다. 갱신 재시도로 25초쯤 걸려 8초까지만 기다린다. L5 |
| 낮음 — `location.assign`이라 뒤로 가기에 설정 화면(개인 정보)이 돌아올 수 있다 | `location.replace`. 탈퇴 뒤 이동도 같이. L6 |
| 낮음 — 안내 "Google로 로그인해 주세요"와 버튼 "Google로 시작하기"가 다르다 | "Google로 시작하기를 눌러 주세요"로 |
| 낮음 — 같은 브라우저로 다른 사람이 로그인하면 남은 구독이 넘어간다 | 높음을 고치며 같이 없어졌다 |
| 낮음 — 다른 탭은 401까지 화면이 남는다, 로그아웃 중 다른 버튼, 로그인 화면 안내가 처음부터 있는 `role="status"` | 그대로 둔다(8장) |
| 낮음 — `border-[#f2f4f7]`은 테두리 토큰이 아니다 | 그대로 둔다. 같은 설정 화면의 `BrowserPushSetting`이 쓰는 구분선과 맞췄다 |

## 8. 남은 것

- 모든 기기에서 로그아웃(`scope: "global"`)은 없다. 필요하면 같은 줄에 둘째 버튼으로 더한다.
- 사이드바에는 로그아웃이 없다(설정에만). 사이드바 아래 계정 메뉴를 만들 때 옮길지 정한다.
- 이미 받은 접근 토큰은 만료(1시간)까지 남는다(JWT라 서버에서 거둘 수 없다). 갱신 토큰은 거둬진다.
- 다른 탭은 로그아웃을 바로 알지 못한다. 쿠키를 같이 쓰므로 다음 요청에서 401로 로그인 화면에 간다(그 전까지 화면은 남는다). `onAuthStateChange`로 맞추는 것은 따로 한다.
- 로그아웃하는 동안에도 설정의 다른 버튼은 눌린다(그 요청이 401이면 안내 없는 로그인 화면으로 갈 수 있다, 드묾).
- 로그인 화면의 안내는 처음부터 있는 `role="status"`라 화면 읽기 프로그램이 읽지 않을 수 있다(탈퇴 안내와 같은 기존 방식).

## 10. 코드와 패치

### 코드 (새 파일)

#### `web/src/components/SignOutSetting.tsx`

````tsx
import { useState } from "react";
import { signOut } from "@/api/client";
import Button from "@/components/Button";

// 설정 > 계정의 로그아웃 (F-06). 이 기기의 로그인만 끝내고 로그인 화면으로 간다(다른 기기의 로그인과 데이터는 그대로).
// 끝나면 페이지가 바뀐다. 세션을 지우지 못하면(만료된 로그인을 갱신하다 연결이 끊긴 때 등) 그 자리에서 알리고 다시 누르게 한다
export default function SignOutSetting() {
  const [pending, setPending] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const run = async () => {
    setPending(true);
    setError(null);
    try {
      await signOut();
    } catch {
      setError("로그아웃하지 못했어요. 인터넷 연결을 확인하고 다시 눌러 주세요.");
      setPending(false);
    }
  };

  return (
    <div className="mt-4 flex items-center justify-between gap-4 border-t border-[#f2f4f7] pt-4">
      <div>
        <p className="text-[14px] font-semibold">로그아웃</p>
        <p className="mt-1 text-[12px] text-[#667085]">이 기기에서만 로그아웃해요. 저장한 정보는 그대로 남아요.</p>
````
