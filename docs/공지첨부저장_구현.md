## 정한 것

1. **받는 법은 녹화 그대로다.** 공지 응답의 첨부 `url`(`/files/{id}/download?…&verifier=…`)로 **토큰 없이** GET하면
   LearningX가 파일 저장소(네이버 클라우드)의 서명 주소로 302를 주고, 거기서 파일이 온다. 토큰만으로는 `/login`으로
   간다(녹화 ④). 그래서 첨부 받기는 기존 클라이언트 규칙("리다이렉트는 따라가지 않는다")의 예외로 두되 좁게 열었다
   — `https`로만, 세 번까지, 우리 LearningX의 다른 경로(로그인 화면)로 가면 실패, 첨부가 HTML이 아닌데 HTML이 오면
   실패. 우리 LearningX의 받기 경로가 아닌 주소는 **보내기 전에** 거절한다(`ALLOWED_DOWNLOADS`).
2. **주소는 어디에도 남기지 않는다.** verifier 주소와 저장소 서명 주소는 그 자체로 열쇠다. 공지 표의 첨부 목록에는
   번호·이름·크기·형식만 넣고, 실행 기록(`tool_calls`)에는 수만 남긴다. httpx가 요청 주소를 INFO로 찍는데, 처음에는
   그 줄에 verifier가 그대로 나왔다(시험이 먼저 잡았다) → 로그 가림에 `verifier=`·`X-Amz-Signature=`·
   `X-Amz-Credential=`을 더했다. 메모리에서도 `repr`에 안 나오게 했다.
3. **20MB 상한·형식 무관**(네 선택). 크기는 공지 목록의 `size`로 먼저 거르고, 받으면서 한 번 더 잰다(목록과
   다르면 받다가 멈춘다). 상한은 업로드와 같은 `MAX_BYTES`를 쓴다 — 둘이 따로 놀지 않게.
4. **학생마다 한 번 저장한다.** PRD 메모("강의자료·첨부파일은 교수 저작물이므로 사용자 간에 공유하지 않는다")와
   ERD 5장이 정한 그대로다. `files`에 `origin = lms_attachment`·`kind = lecture_material`·`external_ref` =
   Canvas 첨부 번호·`lms_course_id` = 내 과목 행으로 넣고, `(user_id, external_ref)` 유니크가 두 번째를 막는다.
   같은 첨부가 공지 두 개에 붙어 있어도 한 번만 받는다.
5. **저장소 경로에 원래 이름을 넣지 않는다**: `<user_id>/lecture_material/<file_id>.<확장자>`(업로드와 같은 꼴).
   이름에 `../`·한글·공백이 섞여도 경로가 깨지지 않는다. 원래 이름은 `original_name`에 둔다.
6. **한 동기화에 10개까지, 최근 공지부터.** 연결 직후에는 한 학기치 공지가 한꺼번에 들어온다. 30분 배치가 50명을
   도는데 한 사람이 큰 파일 수십 개를 붙들면 뒤 사람이 밀린다. 남은 것은 다음 동기화가 받는다.
7. **첨부를 못 받아도 동기화는 성공이고 연결 상태도 그대로다.** 토큰 문제가 아니어서 `LearningXError`(401이면 연결을
   `error`로 바꾼다)와 다른 예외(`AttachmentUnavailable`)로 분리했다. 못 받은 첨부는 "저장 전"으로 남고 다음 동기화가
   다시 받는다. 받은 수는 실행 단계 `save_lms_attachments`("공지 첨부 저장")에 남고, 동기화 결과(`GET /runs`의
   `result`)는 바꾸지 않았다.
8. **올렸는데 기록을 못 남기면 올린 것을 지운다**(그새 탈퇴·DB 오류·같은 첨부가 먼저 들어옴). 저장소에 주인 없는
   파일이 남지 않는다. 탈퇴(`DELETE /me`)는 이미 `files.storage_path`를 전부 지우므로 받은 첨부도 같이 지워진다.
   단 기록을 넣은 뒤 커밋 중에 끊기면 파일은 둔다(기록이 됐을 수 있다 — 10/21, docs/첨부커밋_구현.md).
9. **분반 한정 공지의 첨부는 받지 않는다.** 화면에 내려주지 않는 공지다(명세 9장).
10. **저장소 설정이 없는 서버는 받지 않는다**(지금 네 `api/.env`가 그렇다). 서버는 그대로 뜨고 동기화도 돈다 —
    첨부만 "저장 전"으로 남는다. 켤 때 경고 문구에 "공지 첨부를 저장할 수 있어요"를 더했다.
11. **과목 상세 응답에 `attachments[]`**: `{name, size_bytes, status, file_id}`. `status`는 `saved`(받았다, `file_id`는
    내 파일) · `too_large`(20MB가 넘어 받지 않는다) · `pending`(아직)이다. 공지 표는 과목 공통이라 저장 상태는 표에
    두지 않고 **학생마다 `files`로** 본다 — 다른 학생이 받은 것은 내 상태를 바꾸지 않는다.
12. **"내 자료"(`materials`)에는 첨부를 넣지 않는다.** 같은 과목·같은 종류로 저장돼서 그대로 두면 자료 탭에 섞여
    들어간다(자료 탭의 "받은 PDF 올려서 요약하기" 흐름이 첫 자료를 집는다). `origin = upload`만 보게 했다.
13. **마이그레이션은 `jsonb not null default '[]'` + 배열 검사.** 이미 저장된 공지는 다음 동기화가 다시 저장하면서
    목록을 채운다(동기화는 받은 공지를 매번 upsert한다). 따로 채우는 스크립트가 필요 없다.
14. **시나리오 S23에 넣었다.** 연구 참여 모집 공지에 포스터(PNG)와 20MB가 넘는 녹화본을 붙여, 포스터는 내 문서함·
    저장소에 들어가고(바이트 해시까지 같다) 녹화본은 **받기 요청조차 없다**는 것을 본다.
15. **#60 시험 문제**: 시험이 `Settings()`로 네 `api/.env`를 읽어서, "키가 없을 때" 시험(온통청년·Google·스케줄러)이
    PC에서만 깨졌다. `tests/conftest.py`의 `pytest_configure`에서 `.env` 읽기를 끈다(환경 변수는 그대로 읽는다 —
    CI의 `DATABASE_URL`). 그럴듯한 가짜 `.env`를 두고 돌려 **4개 실패 → 0개**를 확인했다.

## 남은 것

- **(나) 문서함 화면·열기**: 저장한 첨부를 앱에서 열 방법이 아직 없다(공지 탭에는 "저장됨"만). 열 때는 5분짜리 서명
  URL로 주고 `Content-Disposition: attachment`로 내려야 한다 — 형식을 가리지 않고 받았으니 HTML 첨부가 저장소
  도메인에서 그대로 열리면 안 된다.
- **(다) 요약 연결(F-15)**: 모델 비용·토큰 상한이 미결이다.
- **영구 실패 첨부**(교수가 지운 파일 등)는 동기화마다 다시 시도한다. 최근 공지부터라 새 첨부를 막지는 않지만,
  실패가 10개 넘게 쌓이면 그보다 오래된 첨부는 밀린다. 실패를 기억하려면 학생마다 칸이 필요하다(마이그레이션).
- 공지에서 첨부가 빠지면 목록에서는 사라지지만 **이미 받은 파일은 지우지 않는다**(학생 문서함에 남는다). LMS 연결
  해제도 받은 파일을 지우지 않는다(과목·과제 기록과 같다). 탈퇴하면 지운다.
- 크기가 없는 첨부(녹화에서는 없었다)는 받아 보며 잰다. 20MB를 넘으면 멈추고 "저장 전"으로 남아 다음에 또 시도한다.
- 수강생 수만큼 같은 파일이 저장된다(교수 저작물 원칙). 데모 규모에서는 문제없다.

#### `api/app/lms/files.py`

```python
"""공지 첨부를 학생 문서함에 저장한다 (F-54, API 명세 9장).

동기화가 받은 과목 공지의 첨부를 받아 파일 저장소에 올리고 `files`에 남긴다(`origin = lms_attachment`,
`kind = lecture_material`, `external_ref` = Canvas 첨부 번호, `lms_course_id` = 그 과목).

- **사용자마다 따로 저장한다.** 첨부는 교수 저작물이라 사용자 사이에 나누지 않는다(PRD F-53 아래 메모,
  ERD 5장). 같은 첨부는 `(user_id, external_ref)` 유니크라 한 번만 들어간다
- **20MB(업로드 상한)를 넘는 첨부는 받지 않는다.** 형식은 가리지 않는다(10/19 결정). 화면은 공지
  목록의 크기로 "커서 저장하지 않았어요"를 보여 준다
- 한 동기화에서 **10개까지**. 최근 공지의 첨부부터 받고 남은 것은 다음 동기화가 받는다(연결 직후에는
  한 학기 분량의 공지가 한꺼번에 들어온다)
- 분반 한정 공지의 첨부는 받지 않는다 — 화면에 보이지 않는 공지다(명세 9장)
- 받거나 올리는 동안 DB 연결을 쥐지 않는다. 기록은 첨부 하나마다 짧은 트랜잭션이다. 올렸는데 기록을
  못 남기면 올린 것을 지운다(저장소에 주인 없는 파일이 남지 않게)
- 하나가 실패해도 나머지를 계속하고 동기화도 성공이다. 못 받은 첨부는 "저장 전"으로 남아 다음 동기화가
  다시 시도한다. 첨부 주소(verifier가 든 열쇠)는 로그·실행 기록에 남기지 않는다
"""

import hashlib
import logging
import re
from collections.abc import Callable
from contextlib import AbstractAsyncContextManager
from dataclasses import dataclass
from datetime import UTC, datetime
from typing import Literal
from uuid import uuid4

from psycopg import AsyncConnection

from app.agent_log import AgentRun
from app.lms.announcements import CanvasAnnouncement, CanvasAttachment, too_large
from app.lms.client import AttachmentUnavailable, LearningXClient
from app.repositories.files import FileRepository
from app.repositories.lms import CourseRow
from app.schemas.lms import ATTACHMENT_TOOL
from app.uploads import MAX_BYTES
from app.uploads.storage import StorageError, SupabaseStorage

logger = logging.getLogger(__name__)
Connect = Callable[[], AbstractAsyncContextManager[AsyncConnection]]

TOOL = ATTACHMENT_TOOL
MAX_PER_SYNC = 10
FALLBACK_TYPE = "application/octet-stream"
_EXTENSION = re.compile(r"\.([A-Za-z0-9]{1,10})$")
_OLDEST = datetime(1970, 1, 1, tzinfo=UTC)


def storage_path(user_id: str, file_id: str, name: str) -> str:
    """`<user_id>/lecture_material/<file_id>.<확장자>`(업로드와 같은 꼴). 원래 이름은 경로에 넣지 않는다."""
    found = _EXTENSION.search(name)
    extension = found.group(1).lower() if found else "bin"
    return f"{user_id}/lecture_material/{file_id}.{extension}"


@dataclass(frozen=True)
class _Wanted:
    course: CourseRow
    posted_at: datetime | None
    attachment: CanvasAttachment


@dataclass(frozen=True)
class AttachmentOutcome:
    saved: int = 0
    failed: int = 0


class AttachmentSaver:
    def __init__(
        self,
        *,
        transaction: Connect,
        client: LearningXClient,
        storage: SupabaseStorage,
        files: Callable[[AsyncConnection], FileRepository] = FileRepository,
    ) -> None:
        self.transaction = transaction
        self.client = client
        self.storage = storage
        self.files = files

    async def run(
        self,
        run: AgentRun,
        user_id: str,
        notices: list[tuple[CourseRow, list[CanvasAnnouncement]]],
    ) -> AttachmentOutcome:
        """이번에 받은 공지의 첨부 중 아직 저장하지 않은 것을 받는다. 할 것이 없으면 기록도 없다."""
        wanted = _wanted(notices)
        if not wanted:
            return AttachmentOutcome()
        async with self.transaction() as conn:
            have = await self.files(conn).lms_attachment_refs(
                user_id, [_ref(one.attachment) for one in wanted]
            )
        todo = [one for one in wanted if _ref(one.attachment) not in have][:MAX_PER_SYNC]
        if not todo:
            return AttachmentOutcome()
        saved = failed = 0
        async with run.tool(TOOL, {"attachments": len(todo)}) as call:
            for one in todo:
                result = await self._save(user_id, one)
                saved += result == "saved"
                failed += result == "failed"
            call.output = {"saved": saved, "failed": failed}
        return AttachmentOutcome(saved=saved, failed=failed)

    async def _save(self, user_id: str, one: _Wanted) -> Literal["saved", "failed", "skipped"]:
        attachment = one.attachment
        assert attachment.url is not None  # _wanted가 주소 없는 첨부를 뺐다
        try:
            got = await self.client.attachment(
                attachment.url, max_bytes=MAX_BYTES, html_ok=_is_html(attachment.content_type)
            )
        except AttachmentUnavailable as exc:
            logger.warning("공지 첨부를 받지 못했어요: file %s, %s", attachment.canvas_file_id, exc)
            return "failed"
        file_id = str(uuid4())
        path = storage_path(user_id, file_id, attachment.name)
        mime_type = attachment.content_type or _bare(got.content_type) or FALLBACK_TYPE
        try:
            await self.storage.upload(path, got.data, mime_type)
        except StorageError as exc:
            logger.warning(
                "공지 첨부를 저장소에 올리지 못했어요: file %s, %s", attachment.canvas_file_id, exc
            )
            return "failed"
        try:
            async with self.transaction() as conn:
                added = await self.files(conn).add_lms_attachment(
                    user_id,
                    file_id=file_id,
                    course_id=one.course.id,
                    ref=_ref(attachment),
                    path=path,
                    mime_type=mime_type,
                    size_bytes=len(got.data),
                    sha256=hashlib.sha256(got.data).hexdigest(),
                    original_name=attachment.name,
                )
        except Exception as exc:  # 그새 탈퇴했거나 DB가 멈췄다. 올린 것을 지우고 다음 첨부로 간다
            logger.warning(
                "공지 첨부 기록을 남기지 못해 올린 파일을 지워요: file %s, %s",
                attachment.canvas_file_id,
                type(exc).__name__,
            )
            await self._remove(path)
            return "failed"
        if added is None:  # 그새 같은 첨부가 들어왔거나 과목이 내 것이 아니다. 올린 것은 지운다
            await self._remove(path)
            return "skipped"
        return "saved"

    async def _remove(self, path: str) -> None:
        try:
            await self.storage.remove(path)
        except StorageError as exc:
            logger.warning("올린 첨부를 지우지 못했어요: %s", exc)


def _wanted(notices: list[tuple[CourseRow, list[CanvasAnnouncement]]]) -> list[_Wanted]:
    """받을 첨부. 분반 한정 공지·상한을 넘는 것·주소가 없는 것은 뺀다. 최근 공지의 첨부부터."""
    found: dict[int, _Wanted] = {}
    for course, items in notices:
        for notice in items:
            if notice.is_section_specific:
                continue
            for attachment in notice.attachments:
                if attachment.url is None or too_large(attachment.size):
                    continue
                current = found.get(attachment.canvas_file_id)
                # 같은 첨부가 두 공지에 붙어 있으면 최근 공지 쪽으로 센다(한 번만 받는다)
                if current is None or (notice.posted_at or _OLDEST) > (
                    current.posted_at or _OLDEST
                ):
                    found[attachment.canvas_file_id] = _Wanted(course, notice.posted_at, attachment)
    return sorted(
        found.values(),
        key=lambda one: ((one.posted_at or _OLDEST), one.attachment.canvas_file_id),
        reverse=True,
    )


def _ref(attachment: CanvasAttachment) -> str:
    return str(attachment.canvas_file_id)


def _bare(content_type: str | None) -> str | None:
    """`text/html; charset=utf-8` → `text/html`."""
    if not content_type:
        return None
    return content_type.split(";")[0].strip().lower() or None


def _is_html(content_type: str | None) -> bool:
    return _bare(content_type) == "text/html"
```
