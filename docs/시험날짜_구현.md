검토가 문제없다고 본 것: 포스터 시험에 옛 날짜가 남은 곳이 없다. 중복 SQL은 KST 날짜끼리 비교해 같은 날·다음 날이 정확히 갈린다. 마감을 import 때 한 번 계산해도 30일 여유라 자정·18:00 경계와 상관없다. 계획서 시계 고정은 학기 범위와 만든 시각에만 닿고 DB `now()`와 섞이지 않는다. 다른 시험 파일의 날짜는 이미 상대 날짜이거나 시계를 고정한다. 앱 코드에 KST 변환 없이 UTC 날짜를 쓰는 곳은 없다.

## 8. 남은 것

- 포스터 원문(TEXT)의 날짜와 초안 마감이 다르다 — 추출 검증이 날짜 근거까지 원문과 대조하게 되면 맞춘다
