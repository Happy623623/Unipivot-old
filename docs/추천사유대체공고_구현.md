# 추천 사유·대체 공고 구현 (`feat/F-24-recommend-alternatives`)

> 📝 기준: PRD v0.9 F-23·F-24 · API 명세 v0.4 5장(`GET /opportunities`·`GET /opportunities/{id}/alternatives`) · web/CLAUDE.md(판정 라벨: 지원 어려움 → "대체 공고 보기")
> 적용할 곳: **main(4faad26)** 위. 닫힌 창 결과·키 이름 PR과 겹치는 파일이 없어 순서는 상관없다. DB(마이그레이션)는 안 바뀐다.
> 사용자가 고른 것(10/21 오후): 대체 공고는 같은 카테고리 · 지원 가능 · 필요 서류 수가 비슷한 순.

두 가지를 한다.

1. **F-24 추천 사유**: 피드 카드에 "추천 이유 · 학과·학년 조건이 맞아요"를 붙인다. 내 정보로 맞는다고 판정한 조건의 이름을 원문 순서로 셋까지 쓴다(넘으면 "외 N개"). 확인할 조건이 남은 공고(정보 필요·원문 확인)는 "… 조건은 맞아요", 지원 어려움은 쓰지 않는다. LLM 없이 판정 결과(`condition_results`)에서 만든다.
2. **F-23 대체 공고**: `GET /opportunities/{id}/alternatives`. 지원 어려움 공고면 같은 카테고리의 지원 가능 공고를 **필수 서류 수가 비슷한 순**(같으면 마감이 이른 순)으로 셋까지 준다. 상세 아래에 "대체 공고" 칸을 두고, 막혀 있던 "대체 공고 보기" 버튼이 그 칸으로 초점을 옮긴다.

## 3. 합친 뒤 확인

실제 공고(지금 DB에 있는 것)로 한 번 본다.

1. 홈: 지원 가능 카드 몇 개에 "추천 이유 · …"가 보인다(조건이 없는 공고·기타 조건만 있는 공고는 없다).
2. 홈 맨 아래 "지원 어려움 N개"를 펼쳐 공고 하나를 연다 → 위의 "대체 공고 보기"를 누르면 아래 "대체 공고" 칸으로 내려가고, 같은 카테고리의 지원 가능 공고가 셋까지 보인다(없으면 "홈으로" 안내).
3. 지원 가능 공고 상세에는 그 칸이 없다.

## 8. 남은 것

- 이미 준비한 공고도 대체 공고로 나온다. 빼려면 말해 줘.
- 추천 사유는 지원 가능·확인 필요 공고만이고, 조건이 없는 공고("누구나")에는 붙지 않는다.
- 목 모드의 대체 공고는 서류 수가 없어 마감 순으로만 고른다.
- "비슷한 난이도"는 서류 수로만 본다(마감까지 남은 날·조건 수는 안 본다).
