# 파일 저장소 — 이미 없는 파일 지우기는 지나간다(Supabase `NoSuchKey`)

> 📝 기준: API 명세 v0.4 4장 `DELETE /me`("이미 지운 파일은 없는 것으로 지나간다") · PRD v0.9 F-06 · 2026-10-19
>
> 적용할 곳: **저장소 새 키 PR(`docs/저장소새키_구현.md`)까지 합친 main** 위 새 브랜치. 같은 파일을 고쳐서 그
> PR이 먼저 들어가야 패치가 맞는다. **마이그레이션 없음** · 명세·PRD·ERD 안 바뀜

10/19 네 PC에서 실제 Supabase에 이미 지운 파일을 한 번 더 지워 봤다. 답은 404가 아니라 이것이었다.

```
400 {"statusCode":"404","error":"not_found","message":"Object not found","code":"NoSuchKey"}
```

Supabase는 오류를 다 HTTP 400으로 주고 진짜 이유는 본문의 `code`에 둔다. 그런데 우리 코드는 지우기에서
404·410만 "이미 없음"으로 봤다. 그래서 **탈퇴가 파일을 몇 개 지우고 멈춘 뒤 다시 누르면, 앞서 지운 첫
파일에서 `502 STORAGE_API_ERROR`가 나고 그 뒤로 계속 막힌다.** 대시보드에서 파일을 직접 지운 경우도 같다.
명세 4장은 이미 "이미 지운 파일은 없는 것으로 지나간다"고 정해 뒀는데, 코드가 실제 Supabase의 답을 몰랐다.

| 값 | 결과 |
| --- | --- |
| 테스트 | **1497 passed**(1490 → +7) · DB 없이 1151 passed, 346 skipped |
| 탈퇴 다시 누르기 E2E | 첨부 하나를 저장한 학생의 파일을 저장소에서만 지우고 `DELETE /me` → 새 키 PR까지만이면 **502**, 프로필 그대로, 로그 `(400, NoSuchKey: Object not found)` → 이 PR이면 **204**, 프로필·`files` 0행 |
| 되돌림 시험 | 돌연변이 **7개 전부 잡힘** |
| 마이그레이션 | 없음 |
| 바뀐 파일 | 2개(`api/app/uploads/storage.py` · `api/tests/test_files_storage.py`). 새 파일 없음 |

## 정한 것

1. **지우기에서 "이미 없음"으로 보는 답은 둘이다.** HTTP 400에 `code: NoSuchKey`(지금 Supabase), 그리고 HTTP
   404·410(예전처럼. 나중에 Supabase가 제대로 된 상태 번호를 줄 때를 위해 둔다).
2. **버킷이 없을 때(`NoSuchBucket`)는 실패로 둔다.** 400이든 404든 같다. 버킷 이름이 틀렸는데 "지웠다"고 넘어가면
   탈퇴한 사람의 파일이 저장소에 그대로 남는다. 이 답은 실제로는 못 봤다 — `NoSuchKey`가 아니면 무엇이든 실패라
   어떤 모양으로 와도 지나가지 않는다.
3. **받기는 바뀌지 않는다.** 없는 파일 받기는 여전히 오류다(포스터 추출·계획서 읽기가 `502`). "이미 없음"은 지우기
   에서만 받아 준다.
4. **오류 본문 읽기는 하나로 모았다**(`_body`). 거절 이유와 "이미 없음" 판단이 같이 쓴다. JSON이 아니거나 객체가
   아니거나 너무 깊으면 빈 것으로 본다.
5. 지우기를 부르는 다른 곳(업로드 되돌리기, 쓰이지 않는 업로드 정리, 공지 첨부 기록 실패 때 되돌리기)도 이미 없는
   파일이면 지나가는 게 맞다. 원래 그러라고 `remove`가 "없으면 지나간다"였다.

## 남은 것

- **버킷이 없을 때 실제 Supabase 답은 못 봤다.** `NoSuchKey`가 아니면 무엇이든 실패로 두어서 어떤 모양이어도
  "지웠다"고 넘어가지는 않는다.
- `files.storage_path`가 실제 위치와 다르면 그 파일은 "이미 없음"으로 지나가고 저장소에 남는다. 지금은 경로를 서버가
  `<user_id>/<kind>/<file_id>.<확장자>` 한 규칙으로만 만들어서 생기지 않는다.
- 앞 PR의 남은 것(문서함 열기, 변수 이름, `%r` 로그 가리기)은 그대로다.
